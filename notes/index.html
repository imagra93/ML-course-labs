ML course notes

Máster en Innovación Tecnológica (MINT) · theory with full derivations

Self-contained notes for the course. Each note has the theory with every derivation, the assumptions of the method with how to check them and what to do when they fail, and code that reproduces every plot and number. The interactive figures are the same ones used in the slides.

Machine learning

# Note Contents
00 Supervised learning, splits and CV problem setup and notation, empirical risk, bias–variance (proof), train/validation/test, K-fold and nested CV, how precise a test metric is, learning curves; assumptions: i.i.d. data, no distribution shift (adversarial validation), grouped and time-ordered data, leakage
01 Linear regression loss, gradient, gradient descent and the learning rate, normal equation, convexity, Newton’s method, MLE, features and scaling, metrics; OLS statistics (standard errors, intervals, Gauss–Markov); assumptions: linearity, independence, homoscedasticity, normality, collinearity and VIF, exogeneity, leverage and influence
02 Logistic regression sigmoid and odds, cross-entropy = MLE, gradient, convexity, Newton/IRLS, separable data, standard errors and odds ratios, metrics, ROC/AUC, thresholds from costs, calibration; assumptions: linearity in the log-odds, events per variable, influential points; class imbalance
02b Generalised linear models distribution + linear score + link, the exponential family, one gradient and one convexity proof for all GLMs, IRLS, deviance; Poisson regression for claim counts, overdispersion (quasi-Poisson, negative binomial), exposure and offsets, Gamma severity, Tweedie pure premium
03 Regularisation, inputs, assumptions Ridge (SVD view, bias–variance), Lasso (coordinate descent), Elastic Net, MAP view, choosing λ; input variables: scaling, encodings (dummy trap, target encoding), missing values, skewed features, outliers, interactions, pipelines and leakage
04 Softmax regression softmax, identifiability, log-sum-exp, cross-entropy, gradient, convexity, multiclass metrics and confusion matrices; assumptions (IIA, exclusive classes), class imbalance, temperature scaling, one-vs-rest vs softmax
05 Support vector classifier margin, Lagrangian, duality and KKT, the dual, SMO, soft margin, kernels and Mercer, hinge loss, sub-gradient descent, multiclass; assumptions and practice: scaling, choosing C and γ, imbalance, Platt probabilities, cost
06 Decision trees and CART entropy and Gini, split search, CART from scratch, regression trees, pruning, instability; what trees assume (no extrapolation, axis-aligned splits, greedy search), categorical and missing values, biased feature importance
07 Bagging, random forests and boosting variance of an average, bootstrap and OOB, random forests, feature importance, AdaBoost as exponential-loss minimisation, gradient boosting, XGBoost’s second-order derivation, boosting in practice, assumptions
