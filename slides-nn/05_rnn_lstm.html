Recurrent Neural Networks:

If we want to build a NN for sequential data, a CNN may not be the best fit: speech, text, the S&P 500, Bitcoin…

  • Sequences have different lengths: an MLP needs a fixed-size input.
  • The order matters, and what happened earlier affects what comes next.
  • The same pattern can appear at any time step: we want to share weights across time, as a CNN shares them across space.

Recurrent neural networks: a class of networks that allow previous outputs to be used as inputs while having hidden states.

Word embeddings - word2vec

Text → tokens (words or sub-words) → integers → vectors.

  • One-hot $\mathbf o_w\in\{0,1\}^{|V|}$: very sparse, high-dimensional, and every pair of words is equally far apart. No similarity information.
  • Embedding: a dense vector $\mathbf e_w\in\R^d$, $d\ll|V|$ (e.g. 50–1,024). Similar words end up close.

An embedding matrix $\bE\in\R^{|V|\times d}$ has one row per word:

$$\mathbf e_w=\bE^\top\mathbf o_w\qquad(\text{just a row lookup})$$

$\bE$ is learned like any other weight: by the task itself (nn.Embedding), or beforehand with target/context likelihood models:

  • word2vec: predict the words around a word (skip-gram), or the word from its neighbours (CBOW).
  • Words used in similar contexts get similar vectors: king − man + woman ≈ queen.

The same idea gives embeddings for sentences and documents: the basis of semantic search and RAG (chapter 6).

Typical Recurrent Neural Networks:

$$\bh^{\langle t\rangle}=g_1\big(\bx^{\langle t\rangle}\bW_x+\bh^{\langle t-1\rangle}\bW_h+\bb_h\big)$$
$$\hat\by^{\langle t\rangle}=g_2\big(\bh^{\langle t\rangle}\bW_y+\bb_y\big)$$

$\bx^{\langle t\rangle}$: feature vector at time $t$ (e.g. a new word of a sentence). $\hat\by^{\langle t\rangle}$: output at time $t$ (e.g. is this word an entity?). $g_1$ is usually tanh. The hidden state $\bh$ carries the memory.

Loss function: summed over the time steps,

$$L(\hat\by,\by)=\sum_{t=1}^{T_y}L\big(\hat\by^{\langle t\rangle},\by^{\langle t\rangle}\big)$$

How do we learn? Backpropagation is done at each point in time: backpropagation through time (BPTT), ordinary backprop on the unrolled graph.

$$\frac{\partial L}{\partial\bW}=\sum_{t=1}^{T}\frac{\partial L^{\langle t\rangle}}{\partial\bW}\Big|_{(t)}$$

$\bW_h$ is used at every step, so its gradient is the sum of the per-step contributions (shared weights → gradients add up).

Recurrent Neural Networks: vanishing gradients

RNNs tend to fail when accessing information from a long time ago. Why? With $\bh_t=\tanh(\mathbf a_t)$:

$$\frac{\partial\bh_t}{\partial\bh_{t-1}}=\mathrm{diag}\big(1-\bh_t^2\big)\bW_h^\top\ \Rightarrow\ \frac{\partial J}{\partial\bh_k}=\frac{\partial J}{\partial\bh_T}\prod_{t=k+1}^T\mathrm{diag}\big(1-\bh_t^2\big)\bW_h^\top$$

Take norms. $\tanh'\le1$, so $\norm{\mathrm{diag}(1-\bh_t^2)}\le1$ and

$$\Big\lVert\frac{\partial J}{\partial\bh_k}\Big\rVert\le\Big\lVert\frac{\partial J}{\partial\bh_T}\Big\rVert\,\norm{\bW_h}^{\,T-k}$$
  • $\norm{\bW_h}\lt1$: the signal from $T-k$ steps back shrinks exponentially (vanishing).
  • Largest singular value $\gt1$: it can blow up (exploding) → gradient clipping.

GRU and LSTMs: gates

To remedy this, several versions of gates have been designed, each with its own purpose, but all with a similar structure:

$$\Gamma=\sigma\big(\bx^{\langle t\rangle}\bW+\bh^{\langle t-1\rangle}\mathbf U+\bb\big)\in(0,1)$$

A gate is a sigmoid: a soft switch between 0 (block) and 1 (let through), applied element-wise. Although all have the same format, each has its own weights and is used in a different way!

Type of gateRoleUsed in
Update gate $\Gamma_u$How much should the past matter now?GRU, LSTM
Relevance gate $\Gamma_r$Drop previous information?GRU, LSTM
Forget gate $\Gamma_f$Erase a cell or not?LSTM
Output gate $\Gamma_o$How much to reveal of a cell?LSTM

GRU and LSTMs: the LSTM cell

$$\begin{aligned}\bff_t&=\sigma\big([\bh_{t-1},\bx_t]\bW_f+\bb_f\big)&&\text{forget: how much old memory to keep}\\\bi_t&=\sigma\big([\bh_{t-1},\bx_t]\bW_i+\bb_i\big)&&\text{input: how much new content to write}\\\tilde\bc_t&=\tanh\big([\bh_{t-1},\bx_t]\bW_c+\bb_c\big)&&\text{candidate content}\\\bc_t&=\hl{\bff_t\odot\bc_{t-1}+\bi_t\odot\tilde\bc_t}&&\text{memory update (additive)}\\\bo_t&=\sigma\big([\bh_{t-1},\bx_t]\bW_o+\bb_o\big)&&\text{output: how much memory to expose}\\\bh_t&=\bo_t\odot\tanh(\bc_t)\end{aligned}$$

Parameters: 4 gate blocks, $4\big(d_h(d_h+d)+d_h\big)$.

GRU and LSTMs: why the gradient survives

Along the memory path:

$$\frac{\partial\bc_t}{\partial\bc_{t-1}}=\mathrm{diag}(\bff_t)\ \ \Rightarrow\ \ \frac{\partial\bc_T}{\partial\bc_k}\approx\prod_{t=k+1}^T\mathrm{diag}(\bff_t)$$

No weight matrix and no squashing derivative in this product: only the forget gates. When the network has learned to remember ($\bff_t\approx1$), the gradient flows back almost unchanged over many steps.

The same idea as the residual connection $\bh=\bx+F(\bx)$: an additive path with a near-identity Jacobian. Tip: initialize the forget-gate bias to a positive value, so the LSTM starts out remembering.

GRU (Gated Recurrent Unit): a lighter cousin with 2 gates and no separate cell state.

$$\tilde\bh_t=\tanh\big([\Gamma_r\odot\bh_{t-1},\bx_t]\bW+\bb\big),\qquad\bh_t=\Gamma_u\odot\tilde\bh_t+(1-\Gamma_u)\odot\bh_{t-1}$$

3 weight blocks instead of 4. Similar accuracy in practice; the LSTM is the safe default for long dependencies.

Other RNN:

  • What happens if we model a very non-linear problem? Deep RNNs: stack recurrent layers, the outputs of one are the inputs of the next.
  • What if the output should not only depend on the past (e.g. S&P 500 values) but also on the future (e.g. classifying words in a sentence)? Bidirectional RNNs: one RNN reads left-to-right, another right-to-left; concatenate their states.

Practicalities: pad sequences to a common length within a batch (and mask the padding), clip gradients (clip_grad_norm_), use the last hidden state (or the mean over time) for many-to-one tasks.
