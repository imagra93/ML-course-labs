Recurrent Neural Networks: why?

If we want to build a NN for sequential data, a CNN may not be the best fit: speech, text, the S&P 500, sensor logs…

  • Sequences have different lengths: an MLP needs a fixed-size input.
  • The order matters: "not good, bad" ≠ "not bad, good".
  • What happened earlier affects what comes next: we need memory.
  • The same pattern can appear at any time step: we want to share weights across time, as a CNN shares them across space.

Recurrent neural networks: networks that read one step at a time and carry a hidden state, a running summary of everything seen so far.

From text to vectors

Tokenize: words, sub-words or characters. Special tokens: <PAD> to fill short sequences, <UNK> for unknown words, <START>. Index: one integer per token in a vocabulary of size $|V|$.

Embed: each id becomes a vector of $d$ learned numbers (next slide). A sentence of $T$ tokens becomes a $T\times d$ matrix, one row per time step: the input of an RNN.

An embedding is a lookup table

Each token id $k$ owns one row $\mathbf e_k$ of a matrix $\bE\in\R^{|V|\times d}$. Written as a one-hot row vector $\mathbf o_k$ (a single 1 in position $k$), the lookup is a matrix product, $\ \mathbf e_k=\mathbf o_k\bE$: it picks row $k$. In code nobody multiplies: E[ids].

$\bE$ starts random and is learned by backprop like any other weight; only the rows of the tokens in the batch get a gradient. nn.Embedding(|V|, d): input $[B,T]$ integers, output $[B,T,d]$ floats. Typical sizes: $|V|$ = 10,000–50,000, $d$ = 50–1,024.

Word embeddings - word2vec

  • One-hot $\mathbf o_w\in\{0,1\}^{|V|}$: very sparse, high-dimensional, and every pair of words is equally far apart. No similarity information.
  • Embedding: a dense vector $\mathbf e_w\in\R^d$, $d\ll|V|$ (e.g. 50–1,024). Similar words end up close.
$$\mathbf e_w=\mathbf o_w\bE\qquad(\text{row }w\text{ of }\bE)$$

$\bE$ is learned like any other weight: by the task itself, or beforehand with target/context likelihood models:

  • word2vec: predict the words around a word (skip-gram), or the word from its neighbours (CBOW).
  • Words used in similar contexts get similar vectors: king − man + woman ≈ queen.

The same idea gives embeddings for sentences and documents: the basis of semantic search and RAG (chapter 6).

The idea: read one word at a time, keep a summary

Like reading a sentence and keeping a mental note: after each word you update the note using the word and the previous note. The note is the hidden state $\bh_t$, a vector of, say, 128 numbers.

The update rule (the "cell") is the same at every step: one set of weights, any sentence length. At the end, $\bh_T$ summarizes the whole review; a dense layer turns it into "positive / negative".

Typical Recurrent Neural Networks:

$$\bh^{\langle t\rangle}=g_1\big(\bx^{\langle t\rangle}\bW_x+\bh^{\langle t-1\rangle}\bW_h+\bb_h\big)$$
$$\hat\by^{\langle t\rangle}=g_2\big(\bh^{\langle t\rangle}\bW_y+\bb_y\big)$$

$\bx^{\langle t\rangle}$: feature vector at time $t$ (e.g. a new word of a sentence). $\hat\by^{\langle t\rangle}$: output at time $t$ (e.g. is this word an entity?). $g_1$ is usually tanh. The hidden state $\bh$ carries the memory. Unrolled, an RNN is just a very deep network whose layers share their weights.

Inside the cell

The cell is a dense layer with two inputs. Equivalently, concatenate them:

$$\bh_t=\tanh\big([\bh_{t-1},\bx_t]\,\bW+\bb\big),\qquad\bW=\begin{pmatrix}\bW_h\\\bW_x\end{pmatrix}$$
objectshape
$\bx_t$ (one step, batch $B$)$B\times d$
$\bh_t$$B\times d_h$
$\bW_x$$d\times d_h$
$\bW_h$$d_h\times d_h$

Parameters: $d\,d_h+d_h^2+d_h$, whatever the length. With $d=100,d_h=128$: 29,312 (PyTorch keeps two bias vectors: 29,440).

out, h_T = rnn(x)        # x: [B, T, 100] → out: [B, T, 128]

An RNN with numbers

0.50

A one-number RNN: $h_t=\tanh(1\cdot x_t+w_h\,h_{t-1})$, $h_0=0$, input sequence $1,0,0,-1,0,0$.

With $w_h=0.5$, each step without input multiplies the memory by about 0.5: after 5 quiet steps, $0.5^5\approx3\%$ of it is left.

Try $w_h\gt1$: the state does not forget, but it is pulled back to a fixed point (0.86 for $w_h=1.5$): the input $-1$ lowers it (0.84 → 0.25) but cannot flip its sign. Only a narrow range in between works: the core problem of plain RNNs.

The same multiplication by $w_h$ happens to the gradient going backward in time.

Training: loss and backpropagation through time

Loss function: summed over the time steps (or only at the last one, for many-to-one):

$$L(\hat\by,\by)=\sum_{t=1}^{T_y}L\big(\hat\by^{\langle t\rangle},\by^{\langle t\rangle}\big)$$

How do we learn? Unroll the network and run ordinary backprop on the unrolled graph: backpropagation through time (BPTT).

$$\frac{\partial L}{\partial\bW_h}=\sum_{t=1}^{T}\frac{\partial L}{\partial\bW_h}\Big|_{\text{step }t}$$

$\bW_h$ is used at every step, so its gradient is the sum of the per-step contributions (shared weights → gradients add up, like the "add gate").

Recurrent Neural Networks: vanishing gradients

With one number per step, $h_t=\tanh(w\,h_{t-1}+u\,x_t)$. The chain rule for one step back:

$$\frac{\partial h_t}{\partial h_{t-1}}=\underbrace{(1-h_t^2)}_{\tanh'}\cdot w$$

Through $T-k$ steps the factors multiply:

$$\frac{\partial h_T}{\partial h_k}=\prod_{t=k+1}^{T}(1-h_t^2)\,w=w^{\,T-k}\prod_{t=k+1}^{T}(1-h_t^2)$$
  • $0\lt1-h_t^2\le1$, so every step back multiplies the gradient by at most $|w|$.
  • $|w|\lt1$: the signal from $T-k$ steps back shrinks exponentially (vanishing). The network cannot learn long-range dependencies: the gradient never tells it they matter.
  • $|w|\gt1$: it can blow up (exploding) → gradient clipping.
  • With vectors, $w$ becomes $\bW_h^\top$ and $1-h_t^2$ a diagonal matrix: $\ \norm{\partial J/\partial\bh_k}\le\norm{\partial J/\partial\bh_T}\,\norm{\bW_h}^{T-k}$.

How fast does the signal fade?

Plain RNN: each step back multiplies the gradient by roughly $\norm{\bW_h}\cdot\tanh'$. LSTM (next slides): along its memory path, only by the forget gate $f$.

  • RNN factor 0.8, 50 steps: $0.8^{50}\approx10^{-5}$.
  • LSTM with $f=0.98$: $0.98^{50}\approx0.36$.

Exploding gradients have a cheap fix: clip the gradient norm (below). Vanishing ones need a new architecture.

GRU and LSTMs: gates

To remedy this, several versions of gates have been designed, each with its own purpose, but all with a similar structure:

$$\Gamma=\sigma\big(\bx^{\langle t\rangle}\bW+\bh^{\langle t-1\rangle}\mathbf U+\bb\big)\in(0,1)$$

A gate is a sigmoid: a soft switch between 0 (block) and 1 (let through), applied element-wise by multiplication. Each gate has its own weights and looks at the current input and the previous state to decide.

Type of gateRoleUsed in
Update gate $\Gamma_u$How much should the past matter now?GRU
Relevance / reset gate $\Gamma_r$Drop previous information?GRU
Forget gate $\Gamma_f$Erase a memory cell or not?LSTM
Input gate $\Gamma_i$Write new content into memory?LSTM
Output gate $\Gamma_o$How much to reveal of a cell?LSTM

Analogy: a notebook (the cell state) with three rules: what to erase (forget), what to write (input), what to read aloud (output).

The LSTM cell

$$\begin{aligned}\bff_t&=\sigma\big([\bh_{t-1},\bx_t]\bW_f+\bb_f\big)\\\bi_t&=\sigma\big([\bh_{t-1},\bx_t]\bW_i+\bb_i\big)\\\tilde\bc_t&=\tanh\big([\bh_{t-1},\bx_t]\bW_c+\bb_c\big)\\\bc_t&=\hl{\bff_t\odot\bc_{t-1}+\bi_t\odot\tilde\bc_t}\\\bo_t&=\sigma\big([\bh_{t-1},\bx_t]\bW_o+\bb_o\big)\\\bh_t&=\bo_t\odot\tanh(\bc_t)\end{aligned}$$

$\bff_t$ forget, $\bi_t$ input, $\bo_t$ output gates; $\tilde\bc_t$ candidate content. The memory update is a sum, highlighted in blue.

Two states travel along time: the cell $\bc_t$ (long-term memory) and the hidden $\bh_t$ (what is shown to the next layer). Parameters: 4 blocks, $4\big(d_h(d_h+d)+d_h\big)$.

The LSTM, one gate at a time

All the gates read the same input: the previous hidden state and the new token, $[\bh_{t-1},\bx_t]$. Each gate has its own weights.

Two states travel along time: the cell $\bc$ (long-term memory, the top line) and the hidden state $\bh$ (the output, bottom right). Press → to follow one update.

1 · Forget gate. For each entry of the memory: keep it (≈ 1) or erase it (≈ 0).

$$\bff_t=\sigma\big([\bh_{t-1},\bx_t]\bW_f+\bb_f\big)$$

Example: a new subject starts a sentence, so the old subject can be forgotten.

2 · Input gate and candidate. What could be written, $\tilde\bc_t\in(-1,1)$, and how much of it, $\bi_t\in(0,1)$:

$$\bi_t=\sigma\big([\bh_{t-1},\bx_t]\bW_i+\bb_i\big)$$$$\tilde\bc_t=\tanh\big([\bh_{t-1},\bx_t]\bW_c+\bb_c\big)$$

3 · Update the memory. Keep part of the old, add part of the new:

$$\bc_t=\bff_t\odot\bc_{t-1}+\bi_t\odot\tilde\bc_t$$

A sum, not a product through a squashing function: with $\bff\approx1$ and $\bi\approx0$ the memory is copied unchanged, step after step. This is what lets information (and the gradient) survive.

4 · Output gate. Which part of the memory to show, to the next layer and to the next step:

$$\bo_t=\sigma\big([\bh_{t-1},\bx_t]\bW_o+\bb_o\big)$$$$\bh_t=\bo_t\odot\tanh(\bc_t)$$

The memory can hold something for a long time without showing it ($\bo\approx0$) and reveal it exactly when it is needed.

One LSTM step, with numbers

One memory cell, old value $c_{t-1}=0.8$. The gates (computed from $\bh_{t-1}$ and $\bx_t$) came out as $f=0.9$, $i=0.3$, $o=0.7$, candidate $\tilde c=-0.5$.

$$c_t=0.9\cdot0.8+0.3\cdot(-0.5)=0.57$$
$$h_t=0.7\cdot\tanh(0.57)=0.36$$

The memory is mostly kept and slightly corrected. With $f=1,i=0$ it would be copied unchanged, for as many steps as needed.

The LSTM reading a sentence

"The cat, which ate a lot, was sleepy": to choose was rather than were, the network must remember that the subject is singular across a whole sub-clause. The gate values are illustrative; a trained LSTM learns this kind of behaviour, spread over many cells.

Why the gradient survives in an LSTM

Along the memory path, $\bc_t=\bff_t\odot\bc_{t-1}+\dots$, so

$$\frac{\partial\bc_t}{\partial\bc_{t-1}}\approx\mathrm{diag}(\bff_t)\ \ \Rightarrow\ \ \frac{\partial\bc_T}{\partial\bc_k}\approx\prod_{t=k+1}^T\mathrm{diag}(\bff_t)$$

No weight matrix and no squashing derivative in this product: only the forget gates. When the network has learned to remember ($\bff_t\approx1$), the gradient flows back almost unchanged over many steps.

The same idea as the residual connection $\bh=\bx+F(\bx)$: an additive path with a near-identity Jacobian. Tip: initialize the forget-gate bias to a positive value, so the LSTM starts out remembering.

The experiment of the notes: the label is the first token, then up to 99 noise tokens. The tip above is the difference between chance and 100 %.

GRU: a lighter cousin

GRU (Gated Recurrent Unit): 2 gates and no separate cell state.

$$\tilde\bh_t=\tanh\big([\Gamma_r\odot\bh_{t-1},\bx_t]\bW+\bb\big)$$
$$\bh_t=\Gamma_u\odot\tilde\bh_t+(1-\Gamma_u)\odot\bh_{t-1}$$

The update gate interpolates between "keep the old state" ($\Gamma_u=0$) and "replace it" ($\Gamma_u=1$): forget and input tied together. 3 weight blocks instead of 4.

Similar accuracy in practice; the LSTM is the safe default for long dependencies, the GRU is a bit faster.

Other RNN: bidirectional and deep

  • What happens if we model a very non-linear problem? Deep RNNs: stack recurrent layers, the outputs of one are the inputs of the next (num_layers=2).
  • What if the output should not only depend on the past (e.g. S&P 500 values) but also on the future (e.g. classifying words in a sentence)? Bidirectional RNNs: one RNN reads left-to-right, another right-to-left; concatenate their states (bidirectional=True).

A bidirectional model needs the whole sequence first: fine for classification, impossible for real-time forecasting or text generation.

Practicalities

  • Batches: pad sequences to a common length. pack_padded_sequence tells the LSTM where each sequence really ends, so the padding is skipped; padding_idx=0 keeps the <PAD> embedding at zero.
  • Many-to-one: use the hidden state after the last real token (what packing returns), or the mean / max over time. Without packing, h[-1] is the state after the padding!
  • Clip gradients (norm 1.0) and use Adam.
class SentimentLSTM(nn.Module):
    def __init__(self, V, d=64, dh=64):
        super().__init__()
        self.emb = nn.Embedding(V, d, padding_idx=0)
        self.lstm = nn.LSTM(d, dh, batch_first=True)
        self.head = nn.Linear(dh, 1)

    def forward(self, tokens, lengths):  # [B, T], [B]
        x = self.emb(tokens)             # [B, T, d]
        x = pack_padded_sequence(x, lengths.cpu(),
                batch_first=True, enforce_sorted=False)
        _, (h, c) = self.lstm(x)         # h: [1, B, dh]
        return self.head(h[-1]).squeeze(1)  # [B] logits

loss_fn = nn.BCEWithLogitsLoss()

The limit of recurrence: one vector for everything

Sequential: step $t$ must wait for step $t-1$. No parallelism over time, slow on GPUs, painful for sequences of thousands of tokens.

Bottleneck: in translation the whole source sentence must fit in one fixed-size vector, and far-away words must survive many multiplications. Next chapter: let every step look directly at every other step.
