Review · Linear regression: the model and the cost

Neural networks are built from the two models of the ML part. A quick review, in the ML notation. Training set $\{(\bx^{(i)},y^{(i)})\}_{i=1}^m$, $y$ a real number.

Hypothesis: a weighted sum of the features (with $x_0=1$),

$$h_{\bth}(\bx)=\theta_0+\theta_1x_1+\dots+\theta_nx_n=\bth^\top\bx$$

Cost: half the mean squared error,

$$J(\bth)=\frac{1}{2m}\sum_{i=1}^m\big(h_{\bth}(\bx^{(i)})-y^{(i)}\big)^2$$

With numbers: the points $(1,1)$, $(2,3)$, $(3,7)$ and the one-parameter model $h=\theta x$. For $\theta=2$ the predictions are $2$, $4$, $6$ and the errors $1$, $1$, $-1$, so $J=\frac{1+1+1}{2\cdot3}=0.5$.

Review · Linear regression: minimizing the cost

Gradient descent: start anywhere and walk downhill. Repeat, for all $j$ at once:

$$\theta_j:=\theta_j-\alpha\,\frac{\partial J(\bth)}{\partial\theta_j}$$

$\alpha$ is the learning rate: too small is slow, too big overshoots (right).

The gradient, by the chain rule:

$$\frac{\partial J(\bth)}{\partial\theta_j}=\frac1m\sum_{i=1}^m\big(h_{\bth}(\bx^{(i)})-y^{(i)}\big)\,x_j^{(i)}$$

each example pushes $\theta_j$ by (its error) × (its input)

With numbers (the three points, $\alpha=0.1$): at $\theta=0.5$, $J'=\frac13\big[(0.5-1)\cdot1+(1-3)\cdot2+(1.5-7)\cdot3\big]=-7$, so $\theta:=0.5-0.1\cdot(-7)=1.2$.

$J$ is convex (a bowl): one minimum, and every start reaches it. Or solve $\nabla J=0$ in one go, the normal equation $\bth=(\bX^\top\bX)^{-1}\bX^\top\by$; here $\theta^*=\frac{\sum xy}{\sum x^2}=\frac{28}{14}=2$.

$h_{\bth}$ is linear in $\bx$: a straight line (a plane, with more features). The errors follow a pattern: the model is too simple, it underfits.

The ML fix: engineer a feature. Add the column $x^2$, so $h=\theta_0+\theta_1x+\theta_2x^2$. Still linear in $\bth$: same cost, same gradient descent (Lab 2).

Here physics told us which column to add. Usually nobody does: with hundreds of inputs, which products, powers or logs? Guessing the features is the real limit.

Review · Logistic regression: the model

Classification, $y\in\{0,1\}$. A line $\bth^\top\bx$ can give $-0.3$ or $1.4$: not a probability. Squash it with the sigmoid $g(z)=\frac{1}{1+e^{-z}}$:

$$h_{\bth}(\bx)=g(\bth^\top\bx)=\frac{1}{1+e^{-\bth^\top\bx}}=P(y=1\mid\bx;\bth)$$

Decision: predict 1 when $h_{\bth}(\bx)\ge0.5$. Since $g(0)=0.5$ and $g$ is increasing,

$$h_{\bth}(\bx)\ge0.5\iff\bth^\top\bx\ge0$$

The decision boundary $\bth^\top\bx=0$ is a straight line (a hyperplane): logistic regression is a linear classifier.

With numbers: $\bth=(-3,1,1)$, so the boundary is the line $x_1+x_2=3$. For $\bx=(2,\,1.5)$: $z=-3+2+1.5=0.5$ and $h=g(0.5)=0.62$, class 1.

Review · Logistic regression: the cost and its minimum

Cost: the binary cross-entropy (log loss), averaged over the examples:

$$J(\bth)=\frac1m\sum_{i=1}^m\Big(-y^{(i)}\log h_{\bth}(\bx^{(i)})-(1-y^{(i)})\log\big(1-h_{\bth}(\bx^{(i)})\big)\Big)$$

With numbers, an example with $y=1$: $h=0.9$ costs $-\log0.9=0.105$, $h=0.1$ costs $-\log0.1=2.303$, 22 times more. Confident mistakes are expensive.

Why not the squared error? With the sigmoid inside it is not convex: flat plateaus with tiny gradients (red, bottom right). The cross-entropy is one smooth bowl.

Gradient: the same shape as for linear regression, only $h$ changed:

$$\frac{\partial J(\bth)}{\partial\theta_j}=\frac1m\sum_{i=1}^m\big(h_{\bth}(\bx^{(i)})-y^{(i)}\big)\,x_j^{(i)}$$

No closed form ($\bth$ sits inside the sigmoid): iterate, with gradient descent (or Newton, L-BFGS in scikit-learn).

Why are they called Neural Networks?

The brain is composed of a lot of small (and "simple") neurons. Each one collects signals from others and "fires" when the total is strong enough.

Neural networks are composed of a lot of small and simple units: each one computes a weighted sum of its inputs and applies a non-linear function.

The power does not come from any single unit, but from connecting many of them in layers.

The analogy with biology stops there: what we train is a big differentiable function, with the same tools as in the ML part of the course (a loss and gradient descent).

Problem Statement:

Same as in supervised learning: given a training set $\{(\bx^{(i)},y^{(i)})\}_{i=1}^m$, learn $h$ so that $h(\bx)$ is a "good" predictor of $y$.

"good" = minimize a loss function!

  • $y$ continuous → regression
  • $y$ discrete → classification
  • A combination of both (e.g. a box and its class in object detection)

What changes is the model family:

  • Linear / logistic regression: $h$ is linear in $\bx$ (or a sigmoid of it).
  • Neural network: $h$ is a composition of many simple functions:
$$h(\bx)=g^{[L]}\Big(\cdots g^{[2]}\big(g^{[1]}(\bx\bW^{[1]}+\bb^{[1]})\,\bW^{[2]}+\bb^{[2]}\big)\cdots\Big)$$

The features are no longer designed by hand: the hidden layers learn them. The next slides build this formula one piece at a time.

The simplest network: one neuron, no activation

You already know this model: it is linear regression.

$$\hat y=w_1x_1+\dots+w_nx_n+b=\mathbf w^\top\bx+b$$
  • New names for old things: the weights $\mathbf w$ are the $\theta_1,\dots,\theta_n$ of the ML part, and the bias $b$ is $\theta_0$.
  • Train it by minimizing the MSE with gradient descent: exactly what you did in the ML labs.
Every neural network is built from this unit, plus one extra ingredient: a non-linear activation applied to $z=\mathbf w^\top\bx+b$.

Logistic Regression is a Neural Net:

Approximate $y$ as a non-linear function of $\bx$:

$$\hat y=\sigma(\mathbf w^\top\bx+b)=\frac{1}{1+e^{-(\mathbf w^\top\bx+b)}}$$

where $\sigma(z)=\frac{1}{1+e^{-z}}$ is the sigmoid function: it squashes any number into $(0,1)$, a probability.

  1. A linear step: $z=\mathbf w^\top\bx+b=w_1x_1+\dots+w_nx_n+b$.
  2. An activation: $a=\sigma(z)$.

Single layer perceptron! One neuron = logistic regression. Every unit of a neural network does exactly these two steps.

One neuron, with numbers

Inputs $\bx=(2,\,-1,\,0.5)$, weights $\mathbf w=(0.4,\,-0.3,\,1.0)$, bias $b=0.1$.

$$z=\sum_i w_ix_i+b=0.8+0.3+0.5+0.1=1.7$$
$$\hat y=\sigma(1.7)=\frac1{1+e^{-1.7}}=0.846$$

Two operations, always the same: a weighted sum (the weights are what we learn) and a squashing function. Positive weights vote "yes", negative ones vote "no", and the bias sets the threshold.

The whole of deep learning is this, repeated millions of times and arranged cleverly.

The limit of linear models: XOR

Proof that no line works. Suppose $w_1x_1+w_2x_2+b$ is positive exactly on the blue points:

  • $(0,0)$ orange: $b\le0$.
  • $(1,0)$ and $(0,1)$ blue: $w_1+b\gt0$ and $w_2+b\gt0$.
  • Add them: $w_1+w_2+b\gt-b\ge0$.
  • But $(1,1)$ is orange: $w_1+w_2+b\le0$. Contradiction. $\blacksquare$

XOR ("one or the other, not both") is the simplest problem where a single neuron fails. Two ways out: invent new features by hand, or let the network learn them.

Fix 1: engineer new features by hand

Circle data: class 1 (blue) inside $x_1^2+x_2^2\lt r^2$. No line separates the classes in the $(x_1,x_2)$ plane.

With the new features $z_1=x_1^2$, $z_2=x_2^2$ the border becomes $z_1+z_2=r^2$: a straight line. Logistic regression on $(z_1,z_2)$ solves it.

For XOR the feature $x_1x_2$ does the job: $\hat y=x_1+x_2-2x_1x_2$ is exactly XOR on the four points.

But you must guess the right features. For a 224×224 photo, which formula of the 150,528 pixel values means "cat"? Nobody knows.

Fix 2: let the model learn useful features from the data. That is exactly what a hidden layer does.

Fix 2: a hidden layer learns the features (XOR by hand)

Two hidden units, each one draws a line:

  • $h_1=\mathrm{step}(x_1+x_2-0.5)$ is OR,
  • $h_2=\mathrm{step}(x_1+x_2-1.5)$ is AND.

The output is a third unit, on $(h_1,h_2)$: $\hat y=\mathrm{step}(h_1-h_2-0.5)$, "OR but not AND" $=$ XOR.

In the new coordinates $(h_1,h_2)$ the four points become $(0,0),(1,0),(1,0),(1,1)$: now a line separates them. The hidden layer changed the representation.

Here we chose the weights by hand. Training finds weights like these automatically, by gradient descent (chapter 2). That is what "learning the features" means.

Multi-layer perceptron:

3 inputs, 4 hidden units, 1 output. Every edge carries one weight: $w_{ij}$ goes from input $i$ to hidden unit $j$.

$a_1=\sigma\big(x_1\class{u1}{w_{11}}+x_2\class{u1}{w_{21}}+x_3\class{u1}{w_{31}}+\class{u1}{b_1}\big)$

$a_2=\sigma\big(x_1\class{u2}{w_{12}}+x_2\class{u2}{w_{22}}+x_3\class{u2}{w_{32}}+\class{u2}{b_2}\big)$

$a_3=\sigma\big(x_1\class{u3}{w_{13}}+x_2\class{u3}{w_{23}}+x_3\class{u3}{w_{33}}+\class{u3}{b_3}\big)$

$a_4=\sigma\big(x_1\class{u4}{w_{14}}+x_2\class{u4}{w_{24}}+x_3\class{u4}{w_{34}}+\class{u4}{b_4}\big)$

$$\ba=\sigma\big(\bx\,\bW^{[1]}+\bb^{[1]}\big)$$

$(1\times3)\cdot(3\times4)+(1\times4)=(1\times4)$: the four units at once. The superscript $[l]$ is the layer.

$$\hat y=\sigma\big(\ba\,\bW^{[2]}+b^{[2]}\big)$$

$(1\times4)\cdot(4\times1)+(1\times1)=(1\times1)$

Each hidden unit is a logistic regression on the inputs. The output is a logistic regression on the hidden units.

Parameters: $3\cdot4+4=16$ in layer 1, $4\cdot1+1=5$ in layer 2. 21 in total. "Fully connected" or "dense": every unit sees every unit of the previous layer.

The neural-network family of this course

All of them are layers of weighted sums + non-linearities, trained with a loss and gradient descent. What changes is how the units are wired, to match the structure of the data.

  • MLP: no structure assumed. CNN: nearby pixels go together, a pattern can appear anywhere.
  • RNN: order matters, keep a running memory. Transformer: any word can relate to any other, all in parallel.

The forward pass, with numbers

One example $\bx=(1,2)$, label $y=1$. Weights chosen by hand (they would normally be random).

Read the weights off the edges: $\bW^{[1]}=\begin{pmatrix}0.5&-0.3\\0.2&0.4\end{pmatrix}$, $\bb^{[1]}=(0.1,-0.1)$, $\bW^{[2]}=\binom{0.7}{-0.5}$, $b^{[2]}=0.2$.

Row $i$ of $\bW^{[1]}$ = the weights leaving input $x_i$; column $j$ = the weights entering hidden unit $j$.

$z_1=1\cdot0.5+2\cdot0.2+0.1=\mathbf{1.000}$

$z_2=1\cdot(-0.3)+2\cdot0.4-0.1=\mathbf{0.400}$

$a_1=\tanh(1.0)=\mathbf{0.762}$, $\ a_2=\tanh(0.4)=\mathbf{0.380}$

These two numbers are the learned features of the example.

$z=0.762\cdot0.7+0.380\cdot(-0.5)+0.2=\mathbf{0.543}$

$\hat y=\sigma(0.543)=\mathbf{0.633}$: the network says "63 % chance of class 1".

$L=-\log0.633=\mathbf{0.458}$. Not terrible, not great. Chapter 2 computes how to change each of the 9 parameters to lower it.

Forward pass = feed the input through the layers, left to right, storing every intermediate value.

Going deeper: features of features

The previous slide pushed one example through a network. Now push every point $(x_1,x_2)$ of the plane through a 2-4-4-1 network trained on the circle data, and paint each unit with its value: one picture per unit.

Each unit computes one number per example: on the previous slide, $a_1=0.762$ for $\bx=(1,2)$. Here every pixel of a picture is one example.

The inputs are the simplest pictures: $x_1$ (left to right) and $x_2$ (bottom to top). Everything else is built from them.

$$\ba^{[1]}=\tanh\big(\bx\bW^{[1]}+\bb^{[1]}\big)$$

A tanh of a weighted sum of $x_1,x_2$ changes in one direction only: each unit of layer 1 draws a soft straight line.

$$\ba^{[2]}=\tanh\big(\ba^{[1]}\bW^{[2]}+\bb^{[2]}\big)$$

Each unit of layer 2 adds up the four lines with its own weights and bends the sum: curved regions, features of features.

$$\hat y=\sigma\big(\ba^{[2]}\bW^{[3]}+b^{[3]}\big)$$

The output combines the regions into a closed region around class 1. Nobody told the network to draw a circle.

Layer 1 draws lines, layer 2 combines lines into regions, the output combines regions. More layers give more complex shapes with fewer units. On images: pixels → edges → textures → parts → objects (chapter 4). That is the deep in deep learning.

Multi-layer perceptron: Matrix notation

Stack the $m$ examples as rows of $\bX$ (so $\bA^{[0]}=\bX$). For each layer $l=1,\dots,L$:

$$\bZ^{[l]}=\bA^{[l-1]}\bW^{[l]}+\bb^{[l]},\qquad\bA^{[l]}=g^{[l]}\big(\bZ^{[l]}\big)$$
objectshape
$\bA^{[l-1]}$$m\times n_{l-1}$
$\bW^{[l]}$$n_{l-1}\times n_l$
$\bb^{[l]}$$1\times n_l$ (added to every row)

The whole forward pass is $L$ matrix products and $L$ element-wise functions: exactly what GPUs are fast at.

Some books write one example as a column, $\mathbf z=\bW\bx+\bb$: the same thing, transposed. The row convention matches PyTorch: nn.Linear(in_features=n, out_features=h) stores its weight as $h\times n$ and computes $\bx\bW^\top+\bb$.

The forward pass is a loop

Every layer does the same two things. Start at $l=0$ with $\bA^{[0]}=\bX$ and feed each output back in as the next input:

A = X                     # l = 0
for l in 1, …, L:
    A = g(A @ W[l] + b[l])   # output → input
Y_hat = A                 # A[L]

$l=0$. Nothing to compute: the input is the "activation" of layer 0.

$$\bA^{[0]}=\bX\qquad(m\times3)$$

One example per row, one feature per column.

$l=1$. In: $\bA^{[0]}$. Out: $\bA^{[1]}$.

$$\bA^{[1]}=\sigma\big(\bA^{[0]}\bW^{[1]}+\bb^{[1]}\big)$$

$(m\times3)(3\times4)+(1\times4)=(m\times4)$

$l=2$. In: $\bA^{[1]}$, the output of the previous step. Out: $\bA^{[2]}$.

Why do we need the derivatives of the activations?

Training a network is gradient descent. For every weight $w$ (and every bias) we repeat

$$w\leftarrow w-\alpha\,\frac{\partial L}{\partial w}$$

So we need $\dfrac{\partial L}{\partial w}$ for every weight. A weight starts a chain: it changes $z$, which changes $a=g(z)$, which changes the loss. The chain rule multiplies the slopes of the links:

$$\frac{\partial L}{\partial w}=\frac{\partial L}{\partial a}\cdot\ho{\frac{\partial a}{\partial z}}\cdot\frac{\partial z}{\partial w}$$

The middle link is always an activation. Its slope is $\dfrac{\partial a}{\partial z}=g'(z)$: how much the output $a$ moves when its input $z$ is nudged, the derivative of the activation function.

Backpropagation (chapter 2) uses these derivatives in every layer, so we compute them once, here: the next slides do it for each activation.

Derivative of the sigmoid

$$\sigma(z)=\frac{1}{1+e^{-z}}=\big(1+e^{-z}\big)^{-1}$$

write the fraction as a power

$$\sigma'(z)=-\big(1+e^{-z}\big)^{-2}\cdot\big(-e^{-z}\big)=\frac{e^{-z}}{\big(1+e^{-z}\big)^2}$$

chain rule: $(u^{-1})'=-u^{-2}\,u'$, and for $u=1+e^{-z}$ we have $u'=-e^{-z}$

$$=\frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}$$

split the square into two factors

$$\sigma'(z)=\sigma(z)\,\big(1-\sigma(z)\big)$$

the first factor is $\sigma(z)$; the second is $1-\sigma(z)$, because $1-\frac{1}{1+e^{-z}}=\frac{e^{-z}}{1+e^{-z}}$

Derivative of tanh

1 · A fraction. Call the top $\hl{N}$ and the bottom $\ho{D}$:

$$\tanh z=\frac{\hl{N}}{\ho{D}},\qquad\hl{N}=e^{z}-e^{-z},\quad\ho{D}=e^{z}+e^{-z}$$

2 · Differentiate the pieces. The derivative of $e^{-z}$ is $-e^{-z}$, so the two pieces swap:

$$\hl{N}'=e^{z}+e^{-z}=\ho{D},\qquad\ho{D}'=e^{z}-e^{-z}=\hl{N}$$

3 · Quotient rule, $\big(\frac{N}{D}\big)'=\frac{N'D-ND'}{D^2}$, with $N'=D$ and $D'=N$:

$$\tanh'z=\frac{\ho{D}\cdot\ho{D}-\hl{N}\cdot\hl{N}}{\ho{D}^2}$$

4 · Split the fraction: $\ \dfrac{D^2}{D^2}-\dfrac{N^2}{D^2}=1-\Big(\dfrac ND\Big)^2$

$$\tanh'z=1-\tanh^2z$$

Numbers. $z=0$: $\tanh=0$ and $\tanh'=1$ (the largest slope). $z=1$: $0.762$ and $1-0.762^2=0.420$. $z=3$: $0.995$ and $0.0099$, almost flat.

Check with the sigmoid: $\tanh z=2\sigma(2z)-1$, so $\tanh'z=4\,\sigma'(2z)=4\cdot\frac{1+\tanh z}{2}\cdot\frac{1-\tanh z}{2}=1-\tanh^2z$. Its slope at 0 is 4 times larger than the sigmoid's.

Derivative of ReLU

$\mathrm{ReLU}(z)=\max(0,z)$ is made of two straight pieces:

$$\mathrm{ReLU}(z)=\begin{cases}0&z\lt0\\z&z\gt0\end{cases}\qquad\qquad\mathrm{ReLU}'(z)=\begin{cases}0&z\lt0\\1&z\gt0\end{cases}$$

the slope of each piece: a flat line has slope 0, the line $y=z$ has slope 1

At $z=0$ the two pieces meet in a corner: no derivative. We simply choose one (PyTorch uses 0). It never matters: $z$ is almost never exactly 0.

GELU: z times a smooth gate

ReLU is "$z$ times a hard gate": $\mathrm{ReLU}(z)=z\cdot\begin{cases}0&z\lt0\\1&z\gt0\end{cases}$. The gate is shut for negative $z$ and open for positive $z$.

GELU keeps the idea, with a smooth gate:

$$\mathrm{GELU}(z)=z\cdot\Phi(z)$$

$\Phi(z)$ (capital phi) is the function that multiplies $z$. It is the share of the bell curve that lies to the left of $z$ (the shaded area, left plot), so it grows smoothly from 0 to 1.

Two things to remember about the derivatives

1 · The slope $g'(z)$ can be computed from the output $a$

$g'(z)=\frac{\partial a}{\partial z}$ is the derivative of the output with respect to its input $z$. In the forward pass we computed $z$ and stored $a=g(z)$. If $g'$ can be written with $a$, nothing has to be computed again: one multiplication.

activation$g'$ with the output
sigmoid$a\,(1-a)$
tanh$1-a^2$
ReLU1 if $a\gt0$, else 0

Sigmoid unit with $z=1$: the stored output is $a=0.731$, so $g'=0.731\cdot0.269=0.197$. Tanh unit of the tiny network, $a=0.76$: $g'=1-0.76^2=0.42$.

2 · Sigmoid shrinks the gradient, ReLU lets it through

In backpropagation (chapter 2) the gradient is multiplied by one $g'$ per layer. The sigmoid never gives more than 0.25:

layers crossed12510
sigmoid, at most0.250.0630.0010.000001
ReLU, active unit1111

After 10 sigmoid layers a gradient is at most a millionth of what it was: the first layers barely learn. A ReLU passes it on unchanged wherever the unit is active.

This is the vanishing gradient, and the main reason why ReLU is the default activation of hidden layers.

Linear activation layer:

  • It is only used for the last layer and a regression problem.
  • Why is it not used in hidden layers?

Proof. With $g(z)=z$ in the hidden layer:

$$\begin{aligned}h(\bx)&=\big(\bx\bW^{[1]}+\bb^{[1]}\big)\bW^{[2]}+\bb^{[2]}\\&=\bx\,\underbrace{\bW^{[1]}\bW^{[2]}}_{\tilde\bW}+\underbrace{\bb^{[1]}\bW^{[2]}+\bb^{[2]}}_{\tilde\bb}\end{aligned}$$

A composition of linear maps is linear: any number of linear layers collapses into one. Depth buys nothing without a non-linearity.

This is why every hidden layer has an activation. The non-linearity is what lets a stack of layers build new features instead of one big linear map. Try it on the next slide: set the activation to Linear and add as many units as you like. The boundary stays a straight line.

With the numbers of the tiny network (the forward-pass example), if we removed the tanh:

$$\tilde\bW=\bW^{[1]}\bW^{[2]}=\begin{pmatrix}0.5&-0.3\\0.2&0.4\end{pmatrix}\begin{pmatrix}0.7\\-0.5\end{pmatrix}=\begin{pmatrix}0.50\\-0.06\end{pmatrix}$$$$\tilde b=\bb^{[1]}\bW^{[2]}+b^{[2]}=0.1\cdot0.7+(-0.1)\cdot(-0.5)+0.2=0.32$$

Nine parameters, but the two-layer "network" is just the single neuron $\hat y=0.50\,x_1-0.06\,x_2+0.32$: three parameters, a straight line.

What did the hidden units learn?

The same network as before (4 tanh units, one layer). Each hidden unit on its own is a logistic regression: a soft line through the plane. None of them can see a circle.

The output unit is another logistic regression on the four hidden activations. Added with the right signs, four half-planes fence in a region. With ReLU the walls are sharp; with more units the fence is rounder.

Different approach:

  • Machine learning: we design features ($x_1^2$, $x_1x_2$, $\sin x$…), then fit a simple model on them.
  • Neural networks: one hidden layer learns a few features from the raw inputs.
  • Deep learning: many layers learn features of features: edges → shapes → objects (chapter 4).

What a loss looks like

Cross-entropy punishes confident mistakes very hard: predicting 0.1 for a positive costs 2.3, predicting 0.01 costs 4.6. Being right and confident costs almost nothing.

The loss of the dataset is the average over examples. Gradient descent lowers that average; it cannot make every example perfect.

MSE squares the error: big errors dominate, outliers pull hard. L1 and Huber (quadratic near 0, linear far away) are more robust: used for box regression in detection.

Rule: pick the loss from the type of $y$, not from taste.

The most useful derivative: sigmoid + cross-entropy

One example, label $y\in\{0,1\}$, prediction $\hat y=\sigma(z)$, loss

$$L=-\big[y\log\hat y+(1-y)\log(1-\hat y)\big]$$

1 · Derivative with respect to the prediction:

$$\frac{\partial L}{\partial\hat y}=-\frac{y}{\hat y}+\frac{1-y}{1-\hat y}=\frac{\hat y-y}{\hat y(1-\hat y)}$$

2 · The slope of the sigmoid, $\sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)$, with $\hat y=\sigma(z)$: $\ \dfrac{\partial\hat y}{\partial z}=\hat y(1-\hat y)$

3 · Chain rule: the two $\hat y(1-\hat y)$ cancel:

$$\frac{\partial L}{\partial z}=\frac{\hat y-y}{\hat y(1-\hat y)}\cdot\hat y(1-\hat y)=\hat y-y$$

What are we computing? Whatever comes before, a binary classifier ends in one neuron: the logit $z^{[L]}$ (a weighted sum of the last hidden layer), the sigmoid, and the prediction $\hat y=a^{[L]}=\sigma(z^{[L]})$. The loss compares $\hat y$ with $y$.

We want $\partial L/\partial z^{[L]}$ (red): how the loss reacts when the logit moves. Chapter 2 builds every other gradient of the network from it.

"Prediction minus target": large when the network is confidently wrong (for $y=1$, a prediction of 0.05 gives $-0.95$), about 0 when it is right. The same happens for softmax + cross-entropy and for a linear output + $\frac12$MSE (coming up).

More than two classes

Binary: two classes

Is this email spam? One output is enough: $\hat y=P(\text{spam})$, a number in $(0,1)$. The other class gets $1-\hat y$.

Multiclass: $K$ classes, one is right

What is in this photo: a cat, a dog, a car, a tree or a boat? We need $K$ numbers: $P(\text{cat}),\dots,P(\text{boat})$. All $\ge0$, and adding up to 1.

  • Digits 0–9 ($K=10$) · iris species ($K=3$) · damage severity: minor, moderate, severe ($K=3$) · the next word of a sentence ($K\approx50\,000$).
  • Multi-label is different: several classes can be true at once (the tags of a photo). Each tag then gets its own independent sigmoid.
The plan: one output neuron per class, and a way to turn the $K$ scores into $K$ probabilities that add up to 1.

The classes as one-hot vectors

A label is a name. How do we write it as numbers? PyTorch counts classes from 0.

Integers are compact, but they invent an order and distances: "car = 2" looks like twice a dog. None of that is true.

One-hot: $K$ entries, a 1 in the position of the true class and 0 elsewhere. No order, every class equally far from the others.

A one-hot vector is also a probability distribution: all the probability on the true class. The network will output another one, $\hat{\mathbf y}$, and training pushes it towards the target $\mathbf y$ (true class: dog):

Both are vectors of $K$ numbers that add up to 1, so they can be compared entry by entry.

For a whole dataset the targets form a matrix $\bY$ with $m$ rows (one per example) and $K$ columns. Each row has a single 1.

A layer of neurons: one score per class

$K$ classes → $K$ neurons side by side, each with its own weights. Each one computes the score of its class, called a logit:

$$z_k=\mathbf w_k^\top\bx+b_k,\qquad k=1,\dots,K$$

All the weights together form a matrix $\bW$ of size $n\times K$, and the whole layer is $\ \bz=\bx\bW+\bb$.

Still linear. The border between two classes is where $z_k=z_j$, i.e. $(\mathbf w_k-\mathbf w_j)^\top\bx+(b_k-b_j)=0$: a straight line. One layer, however wide, cannot draw curved borders.

The scores are not probabilities: they can be negative and they do not add up to 1. One more block turns them into $K$ probabilities: the softmax. (You met this model in the ML part as softmax regression.)

Softmax activation layer:

  • Turns the $K$ scores (logits) of the last layer into $K$ probabilities: all positive, adding up to 1.
  • It is applied to the whole vector of scores at once, not to each number separately like ReLU or the sigmoid.
  • For problems where exactly one class is right.
  • The output is a "soft" version of the one-hot target, and the cross-entropy loss compares the two.

The exponential makes the biggest score dominate (5.1 → 0.90) but never sends the others to exactly 0.

The activation · softmax: $K$ scores → $K$ probabilities
$$\hat y_k=\frac{e^{z_k}}{\sum_{j=1}^Ke^{z_j}},\qquad k=1,\dots,K$$

Exponentiate (every score becomes positive), then divide by the sum (they add up to 1). Dog: $e^{5.1}/181.7=0.90$.

The loss · cross-entropy: compare $\hat{\mathbf y}$ with the one-hot $\mathbf y$
$$L=-\sum_{k=1}^Ky_k\log\hat y_k=-\log\hat y_{\text{true class}}$$

$\mathbf y$ is 0 except at the true class, so only one term survives: minus the log of the probability given to the right answer. Dog: $-\ln0.90=0.10$; cat: $-\ln0.02=3.9$.

What softmax does to the scores:

  • Probabilities, always: positive and adding up to 1, whatever the scores, negative ones included.
  • The order is kept: the largest score gets the largest probability, so the arg-max of the scores is the predicted class.
  • Only differences matter: adding the same number to every score changes nothing (slider "add"). In code the maximum score is subtracted first, so $e^{z}$ cannot overflow.
  • The scale sets the confidence: large scores give a nearly one-hot answer, small ones a nearly uniform one. In chapter 6 the scores are divided by a temperature $T$: the same thing with $s=1/T$.
  • Two classes = sigmoid: for $K=2$, $\hat y_1=\sigma(z_1-z_2)$. Scores $(2,1)$: $\frac{e^2}{e^2+e^1}=0.73=\sigma(1)$.

Softmax - gradient calculation (1/2): what we want

What are we computing? A $K$-class network ends in $K$ neurons: one logit $z_k$ per class, the softmax turns them into $\hat y_1,\dots,\hat y_K$, and the cross-entropy compares those with the one-hot $\mathbf y$.

We want $\partial L/\partial z_j$ for every class $j$ (red). Harder than with the sigmoid: each $z_j$ moves every $\hat y_k$, through the sum in the denominator.

Step 1. Substitute the softmax into the cross-entropy:

$$L=-\sum_jy_j\log\frac{e^{z_j}}{\sum_ke^{z_k}}=-\sum_jy_j\Big(z_j-\log\sum_ke^{z_k}\Big)$$

$\by$ is one-hot: $y_i=1$ for the correct class $i$, 0 for the rest (so $\sum_jy_j=1$). Only the true class survives:

The loss as a function of the scores
$$L=-z_i+\log\sum_ke^{z_k}$$

Two forces: $-z_i$ rewards a high score for the true class; the log-sum of all exponentials penalises every score, mostly the largest ones. Next slide: differentiate it.

Softmax - gradient calculation (2/2): the result

Step 2. Differentiate $L=-z_i+\log\sum_ke^{z_k}$ with respect to every score $z_j$. The log-sum term gives the softmax back:

$$\frac{\partial}{\partial z_j}\log\sum_ke^{z_k}=\frac{e^{z_j}}{\sum_ke^{z_k}}=\hat y_j$$

Case 1 · $j=i$, the correct class

$$\frac{\partial L}{\partial z_i}=-1+\hat y_i=\hat y_i-1$$

Negative (as $\hat y_i<1$): gradient descent pushes the score of the true class up.

Case 2 · $j\ne i$, a wrong class

$$\frac{\partial L}{\partial z_j}=0+\hat y_j=\hat y_j$$

Positive: every wrong score is pushed down, the hardest where the network is most wrongly confident.

$$\frac{\partial L}{\partial z_j}=\hat y_j-y_j\qquad\frac{\partial L}{\partial\bz^{[L]}}=\hat{\mathbf y}-\mathbf y$$

Both cases in one formula, since $y_i=1$ and $y_j=0$: the same prediction minus target as sigmoid + cross-entropy.

The derivative for regression: linear output + MSE

One example, a real-valued label $y$ (a price, a temperature), a linear output $\hat y=z$ (no activation), loss

$$L=\tfrac12\big(\hat y-y\big)^2$$

1 · Derivative with respect to the prediction (the ½ cancels the 2 of the square):

$$\frac{\partial L}{\partial\hat y}=\tfrac12\cdot2\,(\hat y-y)=\hat y-y$$

2 · The slope of the linear activation, $g(z)=z$: $\ \dfrac{\partial\hat y}{\partial z}=g'(z)=1$

3 · Chain rule: nothing to cancel this time.

$$\frac{\partial L}{\partial z}=(\hat y-y)\cdot1=\hat y-y$$

What are we computing? A regression network ends in one neuron without activation: the prediction is the logit itself, $\hat y=a^{[L]}=z^{[L]}$, any real number.

We want $\partial L/\partial z^{[L]}$ (red), as for the two classifiers.

Again prediction minus target. $y=3$, $\hat y=2.5$: $\partial L/\partial z=-0.5$, push the output up. It grows with the error, so an outlier pulls hard. nn.MSELoss has no ½ and averages over the batch: gradient $\frac2m(\hat y-y)$, same direction.

Where the losses come from: maximum likelihood

Say how likely each label is, according to the network. The loss is minus the log of the probability of the label that really happened. Three kinds of label, three losses:

labelthe network saysprobability of the true labelminus the log = the loss
a real numbera bell curve centred on $\hat y$$\propto\exp\!\Big(-\dfrac{(y-\hat y)^2}{2\sigma^2}\Big)$$\tfrac12(y-\hat y)^2$ + constant: the MSE
0 or 1Bernoulli: $P(1)=\hat y$$\hat y^{\,y}\,(1-\hat y)^{1-y}$$-y\log\hat y-(1-y)\log(1-\hat y)$: the BCE
one of $K$categorical: $P(k)=\hat y_k$$\prod_k\hat y_k^{\,y_k}=\hat y_{\text{true}}$$-\sum_ky_k\log\hat y_k$: the cross-entropy
  • Over a dataset the likelihood is a product over examples. The log turns it into a sum, and the minus turns "maximize" into "minimize".
  • Numbers: label 1 and $\hat y=0.8$ costs $-\ln0.8=0.22$; with $\hat y=0.1$ it costs $-\ln0.1=2.30$. Label 3 and $\hat y=2.5$ costs $\tfrac12\cdot0.5^2=0.125$.
  • Same recipe as in the ML part: least squares and logistic regression were maximum likelihood too.

The matching pairs: the gradient is prediction − target

Pair each output layer with its loss, and the derivative with respect to the logit $z$ is always the same simple error:

output layerloss$\partial L/\partial z$
linear$\tfrac12(\hat y-y)^2$$\hat y-y$
sigmoidbinary cross-entropy$\hat y-y$
softmaxcategorical cross-entropy$\hat y_k-y_k$ for each class

The three derivations of this chapter: in each pair the derivative of the activation cancels against the loss.

A mismatched pair is worse. Sigmoid + ½ MSE keeps an extra factor $\hat y(1-\hat y)$. Label $y=1$, logit $z=-5$ ($\hat y=0.0067$):

sigmoid + BCE$\hat y-y=-0.993$
sigmoid + ½ MSE$(\hat y-y)\,\hat y(1-\hat y)=-0.0066$

A gradient 150 times smaller exactly when it should learn fast. Cross-entropy cancels the sigmoid's flat tails.

For a mini-batch of $m$ examples ($J$ = the average loss), the three cases are one matrix formula. It is the error at the output, $\bdelta^{[L]}$ (red):

$$\bdelta^{[L]}=\frac{\partial J}{\partial\bZ^{[L]}}=\frac1m\big(\bA^{[L]}-\bY\big)$$

Predictions minus targets, divided by $m$. This is the first line of backpropagation: chapter 2 sends $\bdelta^{[L]}$ back through the network (dashed) to get every other gradient.

Universal approximation

A network with one hidden layer and enough units can approximate any continuous function on a bounded interval.

A constructive picture. Two steep sigmoids make a step up and a step down:

$$\text{bump}_{[a,b]}(x)=\sigma\big(k(x-a)\big)-\sigma\big(k(x-b)\big)$$

Put a bump of height $f(\text{centre})$ on each small interval and add them: the output layer does the adding. More units, finer bumps.

It says such weights exist, not that gradient descent finds them, nor how many units are needed. In practice, depth is far more efficient than width.

4
hidden units used–

The loss is no longer convex

Symmetry argument. Swap two hidden units (their incoming and outgoing weights). The network computes exactly the same function, so the loss is the same.

So if $\mathbf w^*$ is a minimum, the swapped $\mathbf w^{**}$ is another one. Their average $\frac12(\mathbf w^*+\mathbf w^{**})$ gives both units the same weights: generally a worse network.

A convex function would satisfy $J\big(\frac{\mathbf w^*+\mathbf w^{**}}2\big)\le\frac12J(\mathbf w^*)+\frac12J(\mathbf w^{**})$. It fails: not convex. $\blacksquare$

  • Many equivalent minima, plus saddle points and plateaus.
  • The start (random initialization) matters. Large networks usually find good minima anyway.
  • We will need better optimizers than vanilla gradient descent (chapter 3).

Learning workflow:

  • Start with a labelled dataset.
  • Design an architecture (layers, units, activations).
  • Decide a loss function (from the type of $y$).
  • Decide an optimizer (chapter 3).
  • Apply an iterative algorithm (gradient descent): forward, loss, backward, update, repeat.
  • The engine of neural networks: gradient-based optimization!
    • Note: we do not mention the word "convex" anymore.
