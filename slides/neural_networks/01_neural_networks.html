Why are they called Neural Networks?

The brain is composed of a lot of small (and "simple") neurons. Each one collects signals from others and "fires" when the total is strong enough.

Neural networks are composed of a lot of small and simple units: each one computes a weighted sum of its inputs and applies a non-linear function.

The power does not come from any single unit, but from connecting many of them in layers.

The analogy with biology stops there: what we train is a big differentiable function, with the same tools as in the ML part of the course (a loss and gradient descent).

Problem Statement:

Same as in supervised learning: given a training set $\{(\bx^{(i)},y^{(i)})\}_{i=1}^m$, learn $h$ so that $h(\bx)$ is a "good" predictor of $y$.

"good" = minimize a loss function!

  • $y$ continuous → regression
  • $y$ discrete → classification
  • A combination of both (e.g. a box and its class in object detection)

What changes is the model family:

  • Linear / logistic regression: $h$ is linear in $\bx$ (or a sigmoid of it).
  • Neural network: $h$ is a composition of many simple functions:
$$h(\bx)=g^{[L]}\Big(\cdots g^{[2]}\big(g^{[1]}(\bx\bW^{[1]}+\bb^{[1]})\,\bW^{[2]}+\bb^{[2]}\big)\cdots\Big)$$

The features are no longer designed by hand: the hidden layers learn them. The next slides build this formula one piece at a time.

The simplest network: one neuron, no activation

You already know this model: it is linear regression.

$$\hat y=w_1x_1+\dots+w_nx_n+b=\mathbf w^\top\bx+b$$
  • New names for old things: the weights $\mathbf w$ are the $\theta_1,\dots,\theta_n$ of the ML part, and the bias $b$ is $\theta_0$.
  • Train it by minimizing the MSE with gradient descent: exactly what you did in the ML labs.
Every neural network is built from this unit, plus one extra ingredient: a non-linear activation applied to $z=\mathbf w^\top\bx+b$.

Logistic Regression is a Neural Net:

Approximate $y$ as a non-linear function of $\bx$:

$$\hat y=\sigma(\mathbf w^\top\bx+b)=\frac{1}{1+e^{-(\mathbf w^\top\bx+b)}}$$

where $\sigma(z)=\frac{1}{1+e^{-z}}$ is the sigmoid function: it squashes any number into $(0,1)$, a probability.

  1. A linear step: $z=\mathbf w^\top\bx+b=w_1x_1+\dots+w_nx_n+b$.
  2. An activation: $a=\sigma(z)$.

Single layer perceptron! One neuron = logistic regression. Every unit of a neural network does exactly these two steps.

One neuron, with numbers

Inputs $\bx=(2,\,-1,\,0.5)$, weights $\mathbf w=(0.4,\,-0.3,\,1.0)$, bias $b=0.1$.

$$z=\sum_i w_ix_i+b=0.8+0.3+0.5+0.1=1.7$$
$$\hat y=\sigma(1.7)=\frac1{1+e^{-1.7}}=0.846$$

Two operations, always the same: a weighted sum (the weights are what we learn) and a squashing function. Positive weights vote "yes", negative ones vote "no", and the bias sets the threshold.

The whole of deep learning is this, repeated millions of times and arranged cleverly.

Several classes: a layer of neurons

$K$ classes → $K$ neurons side by side, each with its own weights: one score (logit) per class,

$$z_k=\mathbf w_k^\top\bx+b_k,\qquad k=1,\dots,K$$

and the softmax turns the scores into probabilities: $\hat y_k=e^{z_k}/\sum_je^{z_j}$ (details at the end of this chapter).

All the weights together form a matrix: $\bz=\bx\bW+\bb$, with $\bW$ of size $n\times K$. This is the softmax regression of the ML part.

Still linear. The border between two classes is where $z_k=z_j$, i.e. $(\mathbf w_k-\mathbf w_j)^\top\bx+(b_k-b_j)=0$: a straight line. One layer, however wide, cannot draw curved borders.

The limit of linear models: XOR

Proof that no line works. Suppose $w_1x_1+w_2x_2+b$ is positive exactly on the blue points:

  • $(0,0)$ orange: $b\le0$.
  • $(1,0)$ and $(0,1)$ blue: $w_1+b\gt0$ and $w_2+b\gt0$.
  • Add them: $w_1+w_2+b\gt-b\ge0$.
  • But $(1,1)$ is orange: $w_1+w_2+b\le0$. Contradiction. $\blacksquare$

XOR ("one or the other, not both") is the simplest problem where a single neuron fails. Two ways out: invent new features by hand, or let the network learn them.

Fix 1: engineer new features by hand

Circle data: class 1 (blue) inside $x_1^2+x_2^2\lt r^2$. No line separates the classes in the $(x_1,x_2)$ plane.

With the new features $z_1=x_1^2$, $z_2=x_2^2$ the border becomes $z_1+z_2=r^2$: a straight line. Logistic regression on $(z_1,z_2)$ solves it.

For XOR the feature $x_1x_2$ does the job: $\hat y=x_1+x_2-2x_1x_2$ is exactly XOR on the four points.

But you must guess the right features. For a 224×224 photo, which formula of the 150,528 pixel values means "cat"? Nobody knows.

Fix 2: let the model learn useful features from the data. That is exactly what a hidden layer does.

Fix 2: a hidden layer learns the features (XOR by hand)

Two hidden units, each one draws a line:

  • $h_1=\mathrm{step}(x_1+x_2-0.5)$ is OR,
  • $h_2=\mathrm{step}(x_1+x_2-1.5)$ is AND.

The output is a third unit, on $(h_1,h_2)$: $\hat y=\mathrm{step}(h_1-h_2-0.5)$, "OR but not AND" $=$ XOR.

In the new coordinates $(h_1,h_2)$ the four points become $(0,0),(1,0),(1,0),(1,1)$: now a line separates them. The hidden layer changed the representation.

Here we chose the weights by hand. Training finds weights like these automatically, by gradient descent (chapter 2). That is what "learning the features" means.

Multi-layer perceptron:

  • $a_1=\sigma\big(\bW^{[1]\top}_{:,1}\bx+b^{[1]}_1\big)$
  • $a_2=\sigma\big(\bW^{[1]\top}_{:,2}\bx+b^{[1]}_2\big)$
  • $a_3=\sigma\big(\bW^{[1]\top}_{:,3}\bx+b^{[1]}_3\big)$
  • $a_4=\sigma\big(\bW^{[1]\top}_{:,4}\bx+b^{[1]}_4\big)$
  • $h(\bx)=\sigma\big(\bW^{[2]\top}\ba+b^{[2]}\big)$, with $\ba=[a_1,\dots,a_4]$

Column $j$ of $\bW^{[1]}$ holds the weights of hidden unit $j$; the superscript $[l]$ is the layer number.

Each hidden unit is a logistic regression on the inputs. The output is a logistic regression on the hidden units.

Parameters: $3\cdot4+4=16$ in layer 1, $4\cdot1+1=5$ in layer 2. 21 in total. "Fully connected" or "dense": every unit sees every unit of the previous layer.

Going deeper: features of features

A 2-4-4-1 network (two hidden layers, tanh) trained on the circle data. Each heat map shows one unit's value over the whole plane.

$$\ba^{[1]}=g(\bx\bW^{[1]}+\bb^{[1]}),\qquad\ba^{[2]}=g(\ba^{[1]}\bW^{[2]}+\bb^{[2]})$$$$\hat y=\sigma(\ba^{[2]}\bW^{[3]}+b^{[3]})$$

Layer 1 draws lines, layer 2 combines lines into curved regions, the output combines regions. More layers give more complex shapes with fewer units. On images: pixels → edges → textures → parts → objects (chapter 4). That is the deep in deep learning.

The neural-network family of this course

All of them are layers of weighted sums + non-linearities, trained with a loss and gradient descent. What changes is how the units are wired, to match the structure of the data.

  • MLP: no structure assumed. CNN: nearby pixels go together, a pattern can appear anywhere.
  • RNN: order matters, keep a running memory. Transformer: any word can relate to any other, all in parallel.

The forward pass, with numbers

One example $\bx=(1,2)$, label $y=1$. Weights chosen by hand (they would normally be random).

Read the weights off the edges: $\bW^{[1]}=\begin{pmatrix}0.5&-0.3\\0.2&0.4\end{pmatrix}$, $\bb^{[1]}=(0.1,-0.1)$, $\bW^{[2]}=\binom{0.7}{-0.5}$, $b^{[2]}=0.2$.

Row $i$ of $\bW^{[1]}$ = the weights leaving input $x_i$; column $j$ = the weights entering hidden unit $j$.

$z_1=1\cdot0.5+2\cdot0.2+0.1=\mathbf{1.000}$

$z_2=1\cdot(-0.3)+2\cdot0.4-0.1=\mathbf{0.400}$

$a_1=\tanh(1.0)=\mathbf{0.762}$, $\ a_2=\tanh(0.4)=\mathbf{0.380}$

These two numbers are the learned features of the example.

$z=0.762\cdot0.7+0.380\cdot(-0.5)+0.2=\mathbf{0.543}$

$\hat y=\sigma(0.543)=\mathbf{0.633}$: the network says "63 % chance of class 1".

$L=-\log0.633=\mathbf{0.458}$. Not terrible, not great. Chapter 2 computes how to change each of the 9 parameters to lower it.

Forward pass = feed the input through the layers, left to right, storing every intermediate value.

Multi-layer perceptron: Matrix notation

Stack the $m$ examples as rows of $\bX$ (so $\bA^{[0]}=\bX$). For each layer $l=1,\dots,L$:

$$\bZ^{[l]}=\bA^{[l-1]}\bW^{[l]}+\bb^{[l]},\qquad\bA^{[l]}=g^{[l]}\big(\bZ^{[l]}\big)$$
objectshape
$\bA^{[l-1]}$$m\times n_{l-1}$
$\bW^{[l]}$$n_{l-1}\times n_l$
$\bb^{[l]}$$1\times n_l$ (added to every row)
$\bZ^{[l]},\bA^{[l]}$$m\times n_l$

The whole forward pass is $L$ matrix products and $L$ element-wise functions: exactly what GPUs are fast at.

Some books write one example as a column, $\mathbf z=\bW\bx+\bb$: the same thing, transposed. The row convention matches PyTorch: nn.Linear(in_features=n, out_features=h) stores its weight as $h\times n$ and computes $\bx\bW^\top+\bb$.

ReLU is not differentiable at 0; we use a sub-derivative (0 or 1). It never matters in practice. Sigmoid and tanh saturate: their derivative is almost 0 for large $|z|$ (chapter 2 shows why that hurts).

Derivatives of the activations

function g(z)derivative g′(z)

Sigmoid, $\sigma(z)=(1+e^{-z})^{-1}$:

$$\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}=\underbrace{\frac{1}{1+e^{-z}}}_{\sigma(z)}\cdot\underbrace{\frac{e^{-z}}{1+e^{-z}}}_{1-\sigma(z)}$$
$\sigma'(z)=\sigma(z)\,\big(1-\sigma(z)\big)$

Tanh, $\tanh z=\dfrac{e^z-e^{-z}}{e^z+e^{-z}}$, quotient rule:

$$\tanh'z=\frac{(e^z+e^{-z})^2-(e^z-e^{-z})^2}{(e^z+e^{-z})^2}$$$$=1-\frac{(e^z-e^{-z})^2}{(e^z+e^{-z})^2}=1-\tanh^2z$$
$\tanh'(z)=1-\tanh^2(z)$

ReLU, $\max(0,z)$: a line of slope 0, then a line of slope 1.

$\mathrm{ReLU}'(z)=\begin{cases}1&z\gt0\\0&z\lt0\end{cases}$

LeakyReLU: slope $0.01$–$0.2$ instead of 0 for $z\lt0$.

Two things to remember. (1) The derivatives are written with the output $a=g(z)$: $a(1-a)$, $1-a^2$. Backprop reuses the $a$ it stored in the forward pass. (2) $\sigma'\le\frac14$ always shrinks the gradient; ReLU lets it through unchanged (chapter 2).

Linear activation layer:

  • It is only used for the last layer and a regression problem.
  • Why is it not used in hidden layers?

Proof. With $g(z)=z$ in the hidden layer:

$$\begin{aligned}h(\bx)&=\big(\bx\bW^{[1]}+\bb^{[1]}\big)\bW^{[2]}+\bb^{[2]}\\&=\bx\,\underbrace{\bW^{[1]}\bW^{[2]}}_{\tilde\bW}+\underbrace{\bb^{[1]}\bW^{[2]}+\bb^{[2]}}_{\tilde\bb}\end{aligned}$$

A composition of linear maps is linear: any number of linear layers collapses into one. Depth buys nothing without a non-linearity.

This is why every hidden layer has an activation. The non-linearity is what lets a stack of layers build new features instead of one big linear map.

With the numbers of the tiny network (previous slides), if we removed the tanh:

$$\tilde\bW=\begin{pmatrix}0.5&-0.3\\0.2&0.4\end{pmatrix}\begin{pmatrix}0.7\\-0.5\end{pmatrix}=\begin{pmatrix}0.50\\-0.06\end{pmatrix}$$$$\tilde b=0.1\cdot0.7+(-0.1)\cdot(-0.5)+0.2=0.32$$

The two-layer "network" is just the single neuron $\hat y=0.50\,x_1-0.06\,x_2+0.32$.

Try it on the next slide: set the activation to Linear and add as many units as you like. The boundary stays a straight line.

What did the hidden units learn?

The same network as before (4 tanh units, one layer). Each hidden unit on its own is a logistic regression: a soft line through the plane. None of them can see a circle.

The output unit is another logistic regression on the four hidden activations. Added with the right signs, four half-planes fence in a region. With ReLU the walls are sharp; with more units the fence is rounder.

Different approach:

  • Machine learning: we design features ($x_1^2$, $x_1x_2$, $\sin x$…), then fit a simple model on them.
  • Neural networks: one hidden layer learns a few features from the raw inputs.
  • Deep learning: many layers learn features of features: edges → shapes → objects (chapter 4).

The most complex computer-vision networks are just a combination of many "small and easy blocks" that you can understand and even program!

The main ideas behind finding the best weights are the same tools that you already have from machine learning: a loss, its gradient, and gradient descent.

We will explain and understand small blocks, then build complex nets by abstracting each block (like LEGO).

Derivation in two slides.

nn.CrossEntropyLoss and BCEWithLogitsLoss take the raw logits and apply softmax / sigmoid inside, which is numerically safer. nn.NLLLoss expects log-probabilities.

What a loss looks like

Cross-entropy punishes confident mistakes very hard: predicting 0.1 for a positive costs 2.3, predicting 0.01 costs 4.6. Being right and confident costs almost nothing.

The loss of the dataset is the average over examples. Gradient descent lowers that average; it cannot make every example perfect.

MSE squares the error: big errors dominate, outliers pull hard. L1 and Huber (quadratic near 0, linear far away) are more robust: used for box regression in detection.

Rule: pick the loss from the type of $y$, not from taste.

The most useful derivative: sigmoid + cross-entropy

One example, label $y\in\{0,1\}$, prediction $\hat y=\sigma(z)$, loss

$$L=-\big[y\log\hat y+(1-y)\log(1-\hat y)\big]$$

1 · Derivative with respect to the prediction:

$$\frac{\partial L}{\partial\hat y}=-\frac{y}{\hat y}+\frac{1-y}{1-\hat y}=\frac{\hat y-y}{\hat y(1-\hat y)}$$

2 · Derivative of the sigmoid (two slides ago): $\ \dfrac{\partial\hat y}{\partial z}=\hat y(1-\hat y)$

3 · Chain rule: the two $\hat y(1-\hat y)$ cancel:

$$\frac{\partial L}{\partial z}=\frac{\hat y-y}{\hat y(1-\hat y)}\cdot\hat y(1-\hat y)=\hat y-y$$

"Prediction minus target": large when the network is confidently wrong, about 0 when it is right. The same happens for softmax + cross-entropy (next slides) and for a linear output + $\frac12$MSE. Chapter 2 starts from here.

Softmax activation layer:

  • Used for multi-class classification problems (exclusive categories).
  • It is applied to a vector input.
  • Probabilistic interpretation of the output:
    • Looks like a one-hot encoding.
    • Used with the cross-entropy loss.
$$\hat y_k=\frac{e^{z_k}}{\sum_je^{z_j}}$$
$$L=-\sum_ky_k\log\hat y_k=-\log\hat y_{\text{true class}}$$

The exponential makes the biggest score dominate (5.1 → 0.90) but never sends the others to exactly 0. Subtract $\max_kz_k$ before exponentiating to avoid overflow (PyTorch does).

Softmax - gradient calculation:

Step 1. Substitute the softmax into the cross-entropy:

$$L=-\sum_jy_j\log\frac{e^{z_j}}{\sum_ke^{z_k}}=-\sum_jy_j\Big(z_j-\log\sum_ke^{z_k}\Big)$$

Since $\by$ is one-hot ($\sum_jy_j=1$, and $y_i=1$ for the correct class $i$), this simplifies to:

$$L=-\Big(z_i-\log\sum_ke^{z_k}\Big)$$

Step 2. Differentiate with respect to $z_j$. Two cases:

Case 1: $j=i$ (correct class).

$$\frac{\partial L}{\partial z_i}=-\Big(1-\frac{e^{z_i}}{\sum_ke^{z_k}}\Big)=\hat y_i-1$$

Case 2: $j\ne i$ (incorrect classes).

$$\frac{\partial L}{\partial z_j}=-\Big(0-\frac{e^{z_j}}{\sum_ke^{z_k}}\Big)=\hat y_j$$

Vectorized form, for all classes:

$$\frac{\partial L}{\partial z_j}=\hat y_j-y_j$$

With the example above and true class "dog": gradient $=(0.02,\,0.90-1,\,0.05,\,0.01,\,0.02)$: push the dog score up, all the others slightly down.

Universal approximation

A network with one hidden layer and enough units can approximate any continuous function on a bounded interval.

A constructive picture. Two steep sigmoids make a step up and a step down:

$$\text{bump}_{[a,b]}(x)=\sigma\big(k(x-a)\big)-\sigma\big(k(x-b)\big)$$

Put a bump of height $f(\text{centre})$ on each small interval and add them: the output layer does the adding. More units, finer bumps.

It says such weights exist, not that gradient descent finds them, nor how many units are needed. In practice, depth is far more efficient than width.

The loss is no longer convex

Symmetry argument. Swap two hidden units (their incoming and outgoing weights). The network computes exactly the same function, so the loss is the same.

So if $\bth^*$ is a minimum, the swapped $\bth^{**}$ is another one. Their average $\frac12(\bth^*+\bth^{**})$ gives both units the same weights: generally a worse network.

A convex function would satisfy $J\big(\frac{\bth^*+\bth^{**}}2\big)\le\frac12J(\bth^*)+\frac12J(\bth^{**})$. It fails: not convex. $\blacksquare$

  • Many equivalent minima, plus saddle points and plateaus.
  • The start (random initialization) matters. Large networks usually find good minima anyway.
  • We will need better optimizers than vanilla gradient descent (chapter 3).

Learning workflow:

  • Start with a labelled dataset.
  • Design an architecture (layers, units, activations).
  • Decide a loss function (from the type of $y$).
  • Decide an optimizer (chapter 3).
  • Apply an iterative algorithm (gradient descent): forward, loss, backward, update, repeat.
  • The engine of neural networks: gradient-based optimization!
    • Note: we do not mention the word "convex" anymore.

The first step to perform gradient-based optimization is to find the gradients: next chapter.
