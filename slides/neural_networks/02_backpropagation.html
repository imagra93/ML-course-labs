Chapter 1 gave us the forward pass and the loss. Gradient descent needs one more thing: the derivative of the loss with respect to every weight and bias.

A small MLP has thousands of parameters; GPT-2 has 124 million. We need a method that gets all the gradients cheaply and mechanically.

Backpropagation = the chain rule, applied from the loss backwards, reusing what the forward pass already computed.

This chapter: the chain rule on a graph with numbers, one neuron with numbers, the tiny network with numbers, then the general formulas, then two practical topics (initialization, vanishing gradients).

Gradient Calculation:

  • We could write the network as one very complex function and find all derivatives by hand.
    • This is very complex and inefficient.
  • We will use a trick named back-propagation.
    • Modern DL libraries (TensorFlow / PyTorch) construct computational graphs that do exactly this.

How do we calculate the derivatives? Chain rule! If $g_j=g_j(\theta_1,\dots,\theta_p)$ and $J=J(g_1,\dots,g_k)$:

$$\frac{\partial J}{\partial\theta_i}=\sum_{j=1}^k\frac{\partial J}{\partial g_j}\,\frac{\partial g_j}{\partial\theta_i}$$
$$\frac{d f(g(x))}{dx}=\underbrace{\frac{df(g(x))}{dg(x)}}_{\text{outer, at the inner}}\cdot\underbrace{\frac{dg(x)}{dx}}_{\text{inner}}$$

A computation is a graph: $f=(a+b)\cdot c$

Every node does one simple operation. Forward: compute each node from its inputs, left to right.

Backward: start with $\partial f/\partial f=1$ and walk right to left. At each node,

gradient of an input = (gradient of the output) × (local derivative)

Meaning of the result: increase $a$ by a tiny $\epsilon$ and $f$ changes by $-4\epsilon$. Check: $a=2.01\Rightarrow f=7.01\cdot(-4)=-28.04$. ✓

Each node needs only its own local derivative and the number coming from the right. No node has to know the whole formula. That is why it scales to millions of parameters and any architecture.

Three gates to remember

Add (biases, residual connections): the local derivative is 1 for each input, so the upstream gradient is copied to both branches.

Multiply (weight × input): each input's gradient is the upstream gradient times the other input. A weight's gradient is proportional to the activation feeding it: $\partial L/\partial w=\delta\cdot a$.

Max (ReLU, max-pooling): the gradient goes entirely to the input that won; the others get exactly 0.

Every layer in this course is built from these plus the element-wise functions (sigmoid: local derivative $a(1-a)$; tanh: $1-a^2$).

One neuron, forward and backward with numbers

$x=2$, $w=-0.5$, $b=0.3$, label $y=1$, loss $L=-\log a$ (cross-entropy).

Forward. $z=wx+b=-0.7$, $a=\sigma(-0.7)=0.332$, $L=-\log0.332=1.103$. The neuron says 33 % for a positive example: wrong-ish.

$\dfrac{\partial L}{\partial a}=-\dfrac1a=-3.014$. Raising $a$ would lower the loss a lot.

$\dfrac{\partial L}{\partial z}=\dfrac{\partial L}{\partial a}\cdot\sigma'(z)=-3.014\cdot0.222=-0.668$. Note: $=a-y$, the familiar logistic-regression error.

$\dfrac{\partial L}{\partial w}=\dfrac{\partial L}{\partial z}\cdot x=-1.336$, $\ \dfrac{\partial L}{\partial b}=\dfrac{\partial L}{\partial z}=-0.668$. Both negative: increase $w$ and $b$.

$w\leftarrow-0.5-0.5\cdot(-1.336)=0.168$, $\ b\leftarrow0.3-0.5\cdot(-0.668)=0.634$.

$z=0.970$, $a=0.725$, $L=0.321$. One step of gradient descent, and the neuron went from 33 % to 73 % on this example.

Blue numbers were computed left to right and stored. Every red number reuses a blue one.

Why backpropagation is efficient

Naive way: nudge each of the $P$ parameters and re-run the network: $P$ forward passes. A small network has $10^5$ parameters; GPT-2 has $1.2\times10^8$.

Backpropagation = the chain rule applied from the loss backwards, reusing the partial results of the layer above.

  • One forward pass: store every $\bZ^{[l]}$ and $\bA^{[l]}$.
  • One backward pass: every gradient, at roughly the cost of two forward passes.

This is "reverse-mode automatic differentiation". It is why training networks with billions of weights is possible at all. Side effect: training needs several times the memory of inference, because all the activations are kept.

Forward and backward propagation: step by step

forward 1/6

Start. The input batch: $\bA_0=\bX$.

1 · Hidden layer, linear step. A matrix multiplication of the input with the weights, plus the bias:

$$\bZ_1=\bX\bW_1+\bb_1$$

2 · Hidden layer, activation step. $\phi$ can be any differentiable function: sigmoid, ReLU, tanh…

$$\bA_1=\phi(\bZ_1)$$

3 · Output layer, linear step. Same move as step 1, one layer over:

$$\bZ_2=\bA_1\bW_2+\bb_2$$

4 · Output layer, activation step. $\bA_2$ is the network's final prediction:

$$\bA_2=\phi(\bZ_2)$$

5 · The loss compares predictions and targets: $\ L(\bA_2,\bY)$. Forward done: every $\bZ$ and $\bA$ is stored.

Backward starts at the loss. The error signal travels backward, the mirror image of the forward pass.

Error term at the output, $\bdelta_2$. By the chain rule:

$$\bdelta_2=\frac{\partial L}{\partial\bZ_2}=\frac{\partial L}{\partial\bA_2}\odot\phi'(\bZ_2)$$

"How sensitive the loss is to the output layer's raw input." For sigmoid + BCE or softmax + CE it simplifies to $\frac1m(\bA_2-\bY)$.

Gradient with respect to $\bW_2$ and $\bb_2$. Since $\bZ_2=\bA_1\bW_2+\bb_2$ (multiply gate: "the other input"):

$$\frac{\partial L}{\partial\bW_2}=\bA_1^\top\bdelta_2,\qquad\frac{\partial L}{\partial\bb_2}=\sum_{i=1}^m\bdelta_2^{(i)}$$

The bias gradient sums $\bdelta_2$ over all $m$ samples, since every sample shares the same bias.

Send the error back through $\bW_2$:

$$\frac{\partial L}{\partial\bA_1}=\bdelta_2\bW_2^\top$$

This is why it's called back-propagation: $\bdelta_2$ flows backward through $\bW_2^\top$ to reach the hidden layer.

Error term at the hidden layer, $\bdelta_1$. Same chain rule, one layer further back:

$$\bdelta_1=\frac{\partial L}{\partial\bZ_1}=\big(\bdelta_2\bW_2^\top\big)\odot\phi'(\bZ_1)$$

Gradient with respect to $\bW_1$ and $\bb_1$. Exactly the same shape as step 8, one layer earlier ($\bX$ plays the role $\bA_1$ played):

$$\frac{\partial L}{\partial\bW_1}=\bX^\top\bdelta_1,\qquad\frac{\partial L}{\partial\bb_1}=\sum_{i=1}^m\bdelta_1^{(i)}$$

The tiny network: backward with numbers

Same network and example as chapter 1: $\bx=(1,2)$, $y=1$, $\hat y=0.633$, loss –.

Forward values are stored: $\bz_1=(1.0,0.4)$, $\ba_1=(0.762,0.380)$, $z_2=0.543$, $\hat y=0.633$.

$\delta_2=\hat y-y=-0.367$. Negative: the output should go up.

$\partial\bW_2=\ba_1^\top\delta_2=(0.762,0.380)\cdot(-0.367)=(-0.280,-0.140)$. The unit with the larger activation gets the larger gradient.

$\partial\ba_1=\delta_2\bW_2^\top=(-0.257,\,0.184)$: hidden unit 1 (positive weight 0.7) should grow, unit 2 (weight −0.5) should shrink.

$\bdelta_1=(-0.257\cdot0.420,\ 0.184\cdot0.856)=(-0.108,\,0.157)$. Unit 1 is already fairly saturated ($a=0.76$), so its gradient is damped: $1-a^2=0.42$.

$\partial\bW_1=\bx^\top\bdelta_1=\begin{pmatrix}-0.108&0.157\\-0.216&0.314\end{pmatrix}$, $\ \partial\bb_1=(-0.108,0.157)$. Row 2 is twice row 1 because $x_2=2x_1$.

$\bW_2\leftarrow(0.840,-0.430)$, $b_2\leftarrow0.384$, $\bW_1\leftarrow\begin{pmatrix}0.554&-0.379\\0.308&0.243\end{pmatrix}$, $\bb_1\leftarrow(0.154,-0.179)$.

New loss –, down from –. With a mini-batch, every gradient is the average of these numbers over the examples.

Backpropagation: the derivation

Define the error signal of layer $l$: $\ \bdelta^{[l]}=\dfrac{\partial J}{\partial\bZ^{[l]}}\in\R^{m\times n_l}$.

(b) To the weights. In indices, $Z_{ik}=\sum_jA_{ij}W_{jk}+b_k$. $W_{jk}$ affects $Z_{ik}$ for every example $i$, with $\partial Z_{ik}/\partial W_{jk}=A_{ij}$:

$$\frac{\partial J}{\partial W_{jk}}=\sum_i\delta_{ik}A_{ij}=\big(\bA^\top\bdelta\big)_{jk}\ \Rightarrow\ \frac{\partial J}{\partial\bW^{[l]}}=\bA^{[l-1]\top}\bdelta^{[l]}$$

(c) To the previous layer. $A_{ij}$ affects $Z_{ik}$ for every unit $k$, with $\partial Z_{ik}/\partial A_{ij}=W_{jk}$:

$$\frac{\partial J}{\partial A_{ij}}=\sum_k\delta_{ik}W_{jk}=\big(\bdelta\bW^\top\big)_{ij}$$

$g$ acts element by element, so each entry just picks up its local derivative:

$$\bdelta^{[l-1]}=\big(\bdelta^{[l]}\bW^{[l]\top}\big)\odot g'\big(\bZ^{[l-1]}\big)$$

Sanity check with shapes. $\bA^{[l-1]\top}\bdelta^{[l]}$ is $(n_{l-1}\times m)(m\times n_l)=n_{l-1}\times n_l$, the shape of $\bW^{[l]}$. $\ \bdelta^{[l]}\bW^{[l]\top}$ is $m\times n_{l-1}$, the shape of $\bZ^{[l-1]}$. If you forget the formulas, the shapes almost force them.

Link to the ML classes. With one layer ($\bA^{[0]}=\bX$): $\nabla_{\bW}J=\frac1m\bX^\top(\hat\bY-\bY)$. Exactly the gradients of linear and logistic regression: you already knew how to start!

Link to the gates. (b) is the multiply gate ("times the other input", summed over the batch), (c) is the multiply gate the other way round plus a sum over the units, and $\odot g'$ is the element-wise gate.

Forward and backward propagation: the algorithm

Forward →

Start: $\ \bA_0=\bX$

For each layer $k=1,\dots,K+1$:

$$\bZ_k=\bA_{k-1}\bW_k+\bb_k,\qquad\bA_k=\phi_k(\bZ_k)$$

Loss, at the last layer: $\ L(\bA_{K+1},\bY)$. Keep every $\bZ_k,\bA_k$ in memory.

← Backward

Start at the output, $k=K+1$: $\ \bdelta_{K+1}=\dfrac{\partial L}{\partial\bA_{K+1}}\odot\phi'_{K+1}(\bZ_{K+1})$ $\ \big(=\frac1m(\bA_{K+1}-\bY)$ for the matching loss$\big)$

For each layer $k=K+1,\dots,1$:

$$\begin{aligned}\frac{\partial L}{\partial\bW_k}&=\bA_{k-1}^\top\bdelta_k,\qquad\frac{\partial L}{\partial\bb_k}=\sum_i\bdelta_k^{(i)}\\\bdelta_{k-1}&=\big(\bdelta_k\bW_k^\top\big)\odot\phi'_{k-1}(\bZ_{k-1})\end{aligned}$$

Update parameters with gradient descent (learning rate $\eta$):

$$\bW_k:=\bW_k-\eta\frac{\partial L}{\partial\bW_k},\qquad\bb_k:=\bb_k-\eta\frac{\partial L}{\partial\bb_k}$$

Three matrix products per layer in the backward pass. Any layer type (conv, attention…) just needs its own version of these three lines.

Gradient checking, and autograd

A backprop implementation can be subtly wrong and still "train". Check it against a numerical derivative, one parameter at a time:

$$\frac{\partial J}{\partial\theta}\approx\frac{J(\theta+\varepsilon)-J(\theta-\varepsilon)}{2\varepsilon},\qquad\varepsilon\approx10^{-5}$$

The centred difference has error $O(\varepsilon^2)$, much better than the one-sided $O(\varepsilon)$.

Compare with the relative error $\dfrac{\norm{g_{\text{bp}}-g_{\text{num}}}}{\norm{g_{\text{bp}}}+\norm{g_{\text{num}}}}$: below $10^{-7}$ is correct; above $10^{-3}$ is a bug.

Try it on the tiny network: $J(W_2[0]+\varepsilon)-J(W_2[0]-\varepsilon)$ over $2\varepsilon$ gives $-0.280$, the number on the slide before.

Automatic differentiation in PyTorch does all of this for you:

logits = model(X)             # forward: builds the graph
loss = loss_fn(logits, y)
optimizer.zero_grad()         # .grad accumulates: reset it
loss.backward()               # backward: fills p.grad
optimizer.step()              # update
  • Every tensor with requires_grad=True records the operations applied to it (the graph).
  • backward() runs exactly the algorithm of the previous slide, for any graph.
  • with torch.no_grad(): for evaluation: no graph, less memory.

Gradient checking is still the way to test your own layers, and it is what the NumPy lab does.

Weight Initialization:

How would you initialize your weights?

  • All zeros (or all equal)? Every unit in a layer computes the same thing, gets the same $\bdelta$, the same update, and stays identical forever. Random initialization breaks the symmetry.
  • A deep linear chain: $\hat y=\bW^{[L]}\bW^{[L-1]}\cdots\bW^{[1]}\bx$. With every $\bW=1.5\,\bI$: $\hat y=1.5^{L-1}x$, exploding. With $0.5\,\bI$: $0.5^{L-1}x$, vanishing.

How large? For zero-mean independent weights: $\ \mathrm{Var}(z_k)=n_{\text{in}}\,\mathrm{Var}(w)\,\E[a^2]$. Through $L$ layers these factors multiply: we want each to be 1.

  • tanh: $\mathrm{Var}(w)=\frac{1}{n_{\text{in}}}$ (Xavier/Glorot: $\frac{2}{n_{\text{in}}+n_{\text{out}}}$).
  • ReLU zeroes half the signal, $\E[\mathrm{ReLU}(z)^2]=\frac12\E[z^2]$, so $\mathrm{Var}(w)=\frac{2}{n_{\text{in}}}$ (He / Kaiming). PyTorch's defaults are close to these; biases start at 0.

Vanishing and exploding gradients

Unroll the backward formula from the output down to layer $l$:

$$\bdelta^{[l]}=\Big(\cdots\big(\bdelta^{[L]}\bW^{[L]\top}\odot g'(\bZ^{[L-1]})\big)\cdots\bW^{[l+1]\top}\Big)\odot g'(\bZ^{[l]})$$

The gradient reaching an early layer is a product of $L-l$ factors "weight matrix × activation derivative". Products of many numbers shrink or blow up exponentially.

Sigmoid has $\sigma'\le\frac14$: after 10 layers the gradient can be $4^{-10}\approx10^{-6}$. Early layers barely learn: vanishing gradients. Large weights: exploding (loss becomes NaN).

Remedies: ReLU activations · proper initialization · normalization layers (BatchNorm / LayerNorm, ch. 3) · residual connections $\ba^{[l+1]}=\ba^{[l]}+F(\ba^{[l]})$, whose Jacobian contains the identity (ch. 4) · gradient clipping (ch. 5).

Vocabulary of chapter 2

computational graph
the network written as nodes of simple operations. PyTorch builds it during the forward pass.
chain rule
gradient of an input = upstream gradient × local derivative; sum over paths.
backpropagation
the chain rule run from the loss backwards, reusing stored forward values.
error signal $\bdelta^{[l]}$
$\partial J/\partial\bZ^{[l]}$: how much the loss would change if the layer's pre-activations moved.
autograd
PyTorch's automatic backprop: loss.backward() fills every .grad.
gradient checking
comparing backprop with finite differences to catch bugs.
Xavier / He init
random weights with variance $1/n_{\text{in}}$ (tanh) or $2/n_{\text{in}}$ (ReLU) so signals keep their size.
vanishing / exploding
gradients that shrink or grow exponentially with depth, because they are long products.
