Supervised Learning

Notation:

  • $x_j^{(i)}$ feature $j$ of sample $i$
  • $\bx^{(i)}$ feature vector $i$ (size $n\times1$)
  • $y^{(i)}$ target $i$
  • $(\bx^{(i)},y^{(i)})$ training pair $i$
  • $\{(\bx^{(i)},y^{(i)})\}_{i=1}^{m}$ training set
  • $\mathcal{X}$ input space
  • $\mathcal{Y}$ output space
  • $h:\mathcal{X}\to\mathcal{Y}$ hypothesis

Objective:

  • given a training set
  • learn a function $h$ so that $h(\bx)$ is a "good" predictor of $y$.
  • $y$ continuous → regression
  • $y$ discrete → classification

Dataset: Train – Validation – Test

  • Training Dataset.
    • Fit the model – $m$ samples
  • Validation Dataset:
    • Provide an unbiased evaluation
    • Used for tuning model hyperparameters or model selection.
    • Becomes more biased (the model occasionally sees this data, but never does it "learn" from this).
  • Test Dataset.
    • Unbiased evaluation (data never seen).
    • Present results

Dataset: Train – Validation – Test

What if we only have a small dataset?

K-fold cross validation:

  1. Separate test data.
  2. Split data into K folds.
  3. Calculate K metrics:
    • Train on K-1 folds.
    • Validate in the remaining one.
  4. Average the K metrics.

A frequent choice of K is 5 or 10.

$$\mathrm{CV}=\frac{1}{K}\sum_{k=1}^{K}E_k$$
