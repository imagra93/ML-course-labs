Ensemble methods: the idea

Class exercise: how much does an Apple AirTag cost? Everyone writes a guess, without talking to anyone.

Each guess is noisy, but the average of the class is usually close to the real price (35 €).

Averaging $B$ independent guesses, each with variance $\sigma^2$, divides the variance by $B$:

$$\mathrm{Var}\Big(\frac1B\sum_{b=1}^Bh_b\Big)=\frac{\sigma^2}{B}$$

If the guesses are correlated (people talk), with correlation $\rho$ between any two:

$$\mathrm{Var}(\bar h)=\rho\,\sigma^2+\frac{1-\rho}{B}\,\sigma^2$$

Ensemble methods: why averaging works (proof)

$B$ models at a fixed point $\bx$. Each has variance $\mathrm{Var}(h_b)=\sigma^2$, and any two have correlation $\rho$, i.e. covariance $\mathrm{Cov}(h_b,h_{b'})=\rho\,\sigma\cdot\sigma=\rho\sigma^2$.

1 · Variance of a sum = all the variances + the covariances of all pairs:

$$\mathrm{Var}\Big(\sum_{b=1}^Bh_b\Big)=\sum_b\mathrm{Var}(h_b)+\sum_{b\ne b'}\mathrm{Cov}(h_b,h_{b'})$$

2 · Count the terms: $B$ variances, and $B(B-1)$ ordered pairs with $b\ne b'$:

$$=B\sigma^2+B(B-1)\,\rho\sigma^2$$

3 · The average is the sum times $\frac1B$, and $\mathrm{Var}(cX)=c^2\,\mathrm{Var}(X)$:

$$\mathrm{Var}(\bar h)=\frac{B\sigma^2+B(B-1)\rho\sigma^2}{B^2}=\frac{\sigma^2}{B}+\frac{B-1}{B}\,\rho\sigma^2$$

4 · Rearrange, using $\frac{B-1}{B}=1-\frac1B$:

$$=\frac{\sigma^2}{B}+\rho\sigma^2-\frac{\rho\sigma^2}{B}=\rho\sigma^2+\frac{1-\rho}{B}\,\sigma^2\quad\blacksquare$$

Numbers: $\sigma^2=1$, $\rho=0.3$. One model: 1.  $B=10$: $0.3+0.07=0.37$.  $B=100$: $0.307$.  $B\to\infty$: $0.3$.

  • Averaging does not change the bias (the average of the models has the same expected value as one model), so average low-bias models: deep trees.
  • As $B\to\infty$ the second term vanishes: more trees never overfit, the error just levels off.
  • The floor $\rho\sigma^2$ only goes down if the models are less alike.

We have one training set of $m$ examples. To get "different" ones, draw $m$ examples with replacement: a bootstrap sample.

One draw misses a given example with probability $1-\frac1m$. The $m$ draws are independent, so:

$$P(\text{left out})=\Big(1-\frac1m\Big)^m$$
$$\ln\Big(1-\frac1m\Big)^m=m\ln\Big(1-\frac1m\Big)\approx m\cdot\Big(-\frac1m\Big)=-1$$

for a small $u$, $\ln(1-u)\approx-u$

$$P(\text{left out})\xrightarrow{m\to\infty}e^{-1}\approx0.368$$

Each bootstrap sample holds about 63 % of the distinct examples (65 % for $m=10$). The other ~37 % are its out-of-bag (OOB) examples.

For every training example:

  1. take only the trees that did not see it (its OOB trees),
  2. average their predictions for it (example 4: trees 3 and 4),
  3. compare with its true label.

The average error over all examples is the OOB error. Every prediction is made by trees that did not train on that example, so it estimates the test error, like cross-validation, but for free: no extra training and no held-out set.

With many trees, each example is OOB for about 37 % of them. In scikit-learn: RandomForestClassifier(oob_score=True), then read oob_score_.

Ensemble methods: bagging

Bootstrap aggregating (Breiman, 1996):

for b = 1, ..., B:
    draw a bootstrap sample D_b (m examples)
    fit a deep tree h_b on D_b     # no pruning
predict:
    regression:      average of the h_b(x)
    classification:  majority vote
                     (or average the probabilities)

It helps any unstable model (small changes in the data → big changes in the model): deep trees are the classic case. A stable model such as linear regression gains almost nothing.

Ensemble methods: random forest

Random forest (Breiman, 2001) = bagging + one more source of randomness:

  1. Draw $B$ bootstrap samples of the training set.
  2. On each one grow a deep tree, but at every split only a random subset of max_features features may be used (a new subset at each node).
  3. Combine the $B$ trees: majority vote or average of the probabilities (classification), average (regression).

Why the random features? Bagged trees are still correlated: if one feature is very strong, almost every tree puts it at the top, the trees look alike, and $\rho$ stays high.

Random features make the trees less alike: lower $\rho$, lower floor $\rho\sigma^2$. Each tree gets a little worse, but the average gets better.

Typical max_features, with $n$ features: $\sqrt n$ for classification, $n/3$ for regression (scikit-learn's default there is all $n$). Using all $n$ features is plain bagging.

Random forest: review

Pros

  • Much less overfitting than a single tree; very good accuracy with little tuning.
  • No feature scaling; handles non-linear effects and interactions.
  • Robust to outliers in the inputs (trees only use the order of the values).
  • Trees are independent: training runs in parallel. The OOB error comes for free.

Cons

  • Less interpretable than one tree; bigger and slower to predict ($B$ trees).
  • Can't extrapolate beyond the training range.
  • Less suited to very sparse, high-dimensional data (e.g. text), where linear models do well.

Feature importance. MDI (feature_importances_): add up the impurity decreases of all the splits on each feature, averaged over the trees. Free, but computed on training data and biased towards features with many distinct values.

Permutation importance: shuffle one feature in the validation data and measure how much the score drops. More trustworthy.

Boosting: the idea

Bagging: many strong (deep) models trained independently, in parallel. The average lowers the variance.

Boosting: many weak models (shallow trees) trained one after another. Each one focuses on what the ensemble so far gets wrong. It lowers the bias.

The result is an additive model: a weighted sum of $M$ weak learners,

$$F_M(\bx)=\sum_{t=1}^M\alpha_t\,h_t(\bx)$$

Two ways to "focus on the mistakes": AdaBoost re-weights the training examples; gradient boosting fits each new tree to the remaining errors (the residuals).

AdaBoost: the algorithm

Labels $y^{(i)}\in\{-1,+1\}$. Weak learners $h_t(\bx)\in\{-1,+1\}$, usually stumps (trees with a single split). Start with equal weights $w_i=\frac1m$. For $t=1,\dots,M$:

1 · Fit the stump with the smallest weighted error:

$$\varepsilon_t=\sum_{i:\ h_t(\bx^{(i)})\ne y^{(i)}}w_i$$

2 · Its vote, large when its error is small:

$$\alpha_t=\frac12\ln\frac{1-\varepsilon_t}{\varepsilon_t}$$

3 · Re-weight: mistakes up by $e^{\alpha_t}$, hits down by $e^{-\alpha_t}$, then divide by the total so the weights add up to 1:

$$w_i\leftarrow w_i\,e^{-\alpha_t\,y^{(i)}h_t(\bx^{(i)})}$$

$y\,h(\bx)=+1$ if the stump is right, $-1$ if it is wrong

Predict with the weighted vote:

$$H(\bx)=\operatorname{sign}\Big(\sum_{t=1}^M\alpha_t\,h_t(\bx)\Big)$$

Round 1 of the next demo. $m=30$, all $w_i=\frac1{30}$. The best stump misclassifies 5 points:

$$\varepsilon_1=\tfrac{5}{30}=\tfrac16,\qquad\alpha_1=\tfrac12\ln\frac{5/6}{1/6}=\tfrac12\ln5=0.80$$
$$e^{\alpha_1}=\sqrt5,\qquad e^{-\alpha_1}=\tfrac1{\sqrt5}$$

$e^{\frac12\ln5}=5^{1/2}$

$$\text{mistakes: }5\cdot\tfrac{\sqrt5}{30}=0.373\qquad\text{hits: }25\cdot\tfrac{1}{30\sqrt5}=0.373$$

the new weights add up to $0.745$: divide each one by it

each mistake: $\frac1{30}\to\frac1{10}$  ·  each hit: $\frac1{30}\to\frac1{50}$

The 5 mistakes now carry half of the total weight (this always happens), so the next stump cannot ignore them.

A coin flip, $\varepsilon_t=\frac12$, gets $\alpha_t=\frac12\ln1=0$: no vote. Each weak learner only has to be a little better than chance.

Gradient boosting: fit the residuals

Regression with the squared loss. Instead of re-weighting points, each new tree predicts what is still missing: the residual.

  1. Start with a constant: $F_0=\bar y$.
  2. Compute the residuals $r^{(i)}=y^{(i)}-F_{t-1}(\bx^{(i)})$.
  3. Fit a small tree $h_t$ to the pairs $(\bx^{(i)},r^{(i)})$.
  4. Update with a learning rate $\nu$ ("shrinkage"): $F_t=F_{t-1}+\nu\,h_t$. Back to 2.

Why $\nu\lt1$? Many small corrections generalize better than a few big ones.

By hand: 4 points, stumps, $\nu=0.5$. Start: $F_0=\bar y=\frac{2+4+8+10}{4}=6$.

Gradient boosting: why "gradient"?

Treat the predictions at the training points, $F(\bx^{(i)})$, as the parameters, and do a gradient descent step on the loss $\sum_i\ell\big(y^{(i)},F(\bx^{(i)})\big)$:

$$F(\bx^{(i)})\ \leftarrow\ F(\bx^{(i)})-\nu\,\frac{\partial\ell}{\partial F(\bx^{(i)})}$$

Squared loss $\ell=\frac12(y-F)^2$:

$$\frac{\partial\ell}{\partial F}=-(y-F)\ \ \Rightarrow\ \ -\frac{\partial\ell}{\partial F}=y-F=r$$

the negative gradient is the residual

A tree $h_t$ fitted to the negative gradients lets us apply the step at any $\bx$, not only at the training points: $F_t=F_{t-1}+\nu h_t$. Gradient descent "in function space".

Any differentiable loss works: fit each tree to the pseudo-residuals $r^{(i)}=-\partial\ell/\partial F$, evaluated at $F_{t-1}(\bx^{(i)})$.

Log-loss (classification), with $F$ = log-odds and $p=\sigma(F)$:

$$\frac{\partial\ell}{\partial p}=-\frac yp+\frac{1-y}{1-p}=\frac{p-y}{p(1-p)},\qquad\frac{\partial p}{\partial F}=p(1-p)$$
$$\frac{\partial\ell}{\partial F}=\frac{p-y}{p(1-p)}\cdot p(1-p)=p-y\ \ \Rightarrow\ \ r=y-p$$

chain rule; the same cancellation as in logistic regression

$F_0$ is the best constant: the mean of $y$ (squared loss) or the log-odds of the base rate (log-loss).

XGBoost

eXtreme Gradient Boosting: gradient boosting with regularized trees and a very fast implementation.

  • Penalizes complex trees: $\lambda$ (reg_lambda) shrinks the leaf values, and $\gamma$ (gamma) is the minimum gain needed to make a split.
  • Uses the first and second derivatives of the loss (a Newton step).
  • Learning rate eta, row and column subsampling, early stopping, missing values, parallel split search.
  • A top choice for tabular data, with LightGBM and CatBoost. For images, audio and text, deep learning wins.

The value of a leaf (squared loss): the constant $w$ that best fits the leaf's residuals, with an L2 penalty on $w$:

$$\min_w\ \sum_{i\in\text{leaf}}\tfrac12\big(r^{(i)}-w\big)^2+\tfrac12\lambda w^2$$
$$-\sum_{i\in\text{leaf}}\big(r^{(i)}-w\big)+\lambda w=0\ \ \Rightarrow\ \ w\,\big(N_{\text{leaf}}+\lambda\big)=\sum_{i\in\text{leaf}}r^{(i)}$$

derivative with respect to $w$ set to zero, and $\sum_{i\in\text{leaf}}w=N_{\text{leaf}}\,w$

$$w=\frac{\sum_{i\in\text{leaf}}r^{(i)}}{N_{\text{leaf}}+\lambda}$$

$\lambda=0$ gives the mean residual, as in plain gradient boosting. $\lambda\gt0$ shrinks it towards 0, more for small leaves. Example: residuals $\{2,4\}$ and $\lambda=1$ give $w=\frac{6}{3}=2$ instead of 3.
