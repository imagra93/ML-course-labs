Which line should we pick? The SVM chooses the one that stays as far as possible from the closest points: the maximum margin.

Support Vector Machine (SVM): Motivation

In $\R^n$ a hyperplane is an $(n-1)$-dimensional "flat" that cuts the space in two halves.

Support Vector Machine (SVM): Fundamentals

Suppose $\bx\in\R^n$ and $\mathbf w\in\R^n$ are the system's parameters. We define a hyperplane as:

$$\mathbf w\cdot\bx+b=0,\qquad\text{in 2-D: }w_1x_1+w_2x_2+b=0$$

Note: 1 equation, 2 independent variables! One coordinate is free, so the solutions form a line.

$$\text{Decision boundary}=\begin{cases}+1&\text{if }\mathbf w\cdot\bx+b\gt0\\-1&\text{if }\mathbf w\cdot\bx+b\lt0\end{cases}$$

Given $\mathbf w=(1,1)$, $b=-3$, the line $x_1+x_2-3=0$:

Support Vector Machine (SVM): Dot Product

It has two equivalent forms:

$$\mathbf w^\top\bx=w_1x_1+\dots+w_nx_n=\norm{\mathbf w}\,\norm{\bx}\cos\alpha$$ $$\text{with }\norm{\mathbf w}=\sqrt{\textstyle\sum_jw_j^2}$$

$\norm{\bx}\cos\alpha$ is the length of the projection (the "shadow") of $\bx$ on $\mathbf w$. $\norm{\mathbf w}$ only gets in the way, so we use the unit vector:

$$\hat{\mathbf w}=\frac{\mathbf w}{\norm{\mathbf w}}\ \Rightarrow\ \hat{\mathbf w}^\top\bx=\frac{\mathbf w^\top\bx}{\norm{\mathbf w}}=\norm{\bx}\cos\alpha$$

Distances along $\mathbf w$ are differences of shadows, so the signed distance from $\bx$ to the hyperplane is

$$r(\bx)=\frac{\mathbf w\cdot\bx+b}{\norm{\mathbf w}}$$

Check: $\mathbf w=(1,1)$, $b=-3$, $\bx=(4,2)$: $r=3/\sqrt2\approx2.12$. The closest point on the line is $(2.5,0.5)$ and $\norm{(1.5,1.5)}=2.12$ ✓. The sign of the projection says on which side the point is.

Support Vector Machine (SVM): Margin

$$\text{Decision boundary}=\begin{cases}+1&\text{if }\mathbf w\cdot\bx+b\ge\hl{+1}\\-1&\text{if }\mathbf w\cdot\bx+b\le\hl{-1}\end{cases}$$

The goal is to find $\mathbf w$ and $b$ (the hyperplane) such that:

$$\begin{cases}\mathbf w\cdot\bx^{(i)}+b\ge1,&\forall i\text{ with }y^{(i)}=+1\\\mathbf w\cdot\bx^{(i)}+b\le-1,&\forall i\text{ with }y^{(i)}=-1\end{cases}$$ $$\iff\ y^{(i)}\big(\mathbf w\cdot\bx^{(i)}+b\big)\ge1$$

Or equivalently (and only for the support vectors):

$$y^{(i)}\big(\mathbf w\cdot\bx^{(i)}+b\big)-1=0$$

Why ±1? $\mathbf w$ of any scale gives the same line: $(c\mathbf w,cb)$ with $c\gt0$ changes nothing. We spend that freedom by putting the closest points at $f=\pm1$.

Support Vector Machine (SVM): Margin

How do we measure the margin? Projecting! Take a support vector on each side, $\bx_+$ and $\bx_-$:

$$d_+=\frac{\mathbf w\cdot\bx_+}{\norm{\mathbf w}},\qquad d_-=\frac{\mathbf w\cdot\bx_-}{\norm{\mathbf w}}$$ $$d=d_+-d_-=\frac{1}{\norm{\mathbf w}}\big(\mathbf w\cdot\bx_+-\mathbf w\cdot\bx_-\big)$$

For the support vectors, $y^{(i)}(\mathbf w\cdot\bx^{(i)}+b)-1=0$ gives $\mathbf w\cdot\bx_+=1-b$ and $\mathbf w\cdot\bx_-=-1-b$:

$$d=\frac{1}{\norm{\mathbf w}}\big((1-b)-(-1-b)\big)=\frac{1}{\norm{\mathbf w}}(1-b+1+b)$$
$$d=\frac{2}{\norm{\mathbf w}}$$

$b$ cancels. Once the scale is fixed, a short $\mathbf w$ means a wide margin.

Support Vector Machine (SVM): Optimization

20°
margin in this direction–
$$\max_{\mathbf w,b}\ \frac{2}{\norm{\mathbf w}}\quad\text{s.t. }y^{(i)}(\mathbf w\cdot\bx^{(i)}+b)-1\ge0,\ \forall i$$

Maximizing $2/a$ is minimizing $a$, and minimizing $\frac12a^2$ (no square root, cleaner derivative):

$$\min_{\mathbf w,b}\ \frac12\norm{\mathbf w}^2=\frac12\mathbf w^\top\mathbf w$$ $$\text{s.t. }y^{(i)}(\mathbf w\cdot\bx^{(i)}+b)-1\ge0,\ \forall i$$

Only some constraints will affect: the support vectors (circled). This problem is convex and can be solved with quadratic programming (QP) software, or with Lagrange multipliers.

Support Vector Machine (SVM): Optimization

Optimization with inequality constraints. Minimize $f(\mathbf w)$ subject to $g_i(\mathbf w)\le0$ (the primal problem). Build the generalized Lagrangian:

$$\mathcal L(\mathbf w,\boldsymbol\alpha)=f(\mathbf w)+\sum_i\alpha_i\,g_i(\mathbf w),\qquad\alpha_i\ge0$$

At the optimum each constraint is either

  • inactive ($g_i\lt0$): you could move a little without violating it, so it plays no role: $\alpha_i=0$;
  • active ($g_i=0$): the optimum is pressed against it: $\alpha_i\ge0$.

Both cases in one line (complementary slackness, part of the KKT conditions):

$$\alpha_i\,g_i(\mathbf w)=0$$

For the SVM, the active constraints are exactly the support vectors.

Support Vector Machine (SVM): Optimization

To maximize the margin we minimize the norm of $\mathbf w$:

$$\min_{\mathbf w,b}\frac12\norm{\mathbf w}^2\quad\text{subject to}\quad y_i(\mathbf w^\top\bx_i+b)\ge1\ \ \forall i$$

The Lagrangian for the primal problem is:

$$\mathcal L(\mathbf w,b,\boldsymbol\alpha)=\frac12\norm{\mathbf w}^2-\sum_{i=1}^n\alpha_i\big[y_i(\mathbf w^\top\bx_i+b)-1\big]$$

where $\alpha_i\ge0$ are the Lagrange multipliers.

The goal is to minimize the Lagrangian with respect to $\mathbf w$ and $b$, and to maximize it with respect to the non-negative multipliers $\alpha_i$.

Support Vector Machine (SVM): Optimization

Minimizing with respect to $\mathbf w$. The terms involving $\mathbf w$ in the Lagrangian are:

$$\frac12\norm{\mathbf w}^2-\sum_{i=1}^n\alpha_iy_i\,\mathbf w^\top\bx_i$$

Taking the derivative with respect to $\mathbf w$ and setting it to zero:

$$\frac{\partial\mathcal L}{\partial\mathbf w}=\mathbf w-\sum_{i=1}^n\alpha_iy_i\bx_i=\bzero$$
$$\mathbf w=\sum_{i=1}^n\alpha_iy_i\bx_i$$

A key result: the optimal weight vector is a linear combination of the training points, weighted by $\alpha_iy_i$.

Minimizing with respect to $b$. Taking the derivative and setting it to zero:

$$\frac{\partial\mathcal L}{\partial b}=-\sum_{i=1}^n\alpha_iy_i=0$$

This gives the condition:

$$\sum_{i=1}^n\alpha_iy_i=0$$

Support Vector Machine (SVM): Optimization

Now substitute $\mathbf w=\sum_i\alpha_iy_i\bx_i$ and $\sum_i\alpha_iy_i=0$ into the Lagrangian (the $b$ term vanishes):

$$\mathcal L(\boldsymbol\alpha)=\frac12\Big(\sum_i\alpha_iy_i\bx_i\Big)^\top\Big(\sum_j\alpha_jy_j\bx_j\Big)$$ $$\qquad-\sum_i\alpha_iy_i\Big(\sum_j\alpha_jy_j\bx_j\Big)^\top\bx_i+\sum_i\alpha_i$$

Both double sums equal $\sum_{i,j}\alpha_i\alpha_jy_iy_j\bx_i^\top\bx_j$: half of it minus all of it leaves minus half.

Thus, the dual optimization problem is:

$$\max_{\boldsymbol\alpha}\ \sum_i\alpha_i-\frac12\sum_{i}\sum_{j}\alpha_i\alpha_jy_iy_j\,\hl{\bx_i^\top\bx_j}\quad\text{s.t. }\sum_i\alpha_iy_i=0,\ \ \alpha_i\ge0$$

A quadratic program that only depends on the dot products $\bx_i^\top\bx_j$ of the inputs, not directly on $\mathbf w$.

KKT: $\alpha_i\big[y_i(\mathbf w^\top\bx_i+b)-1\big]=0$, so $\alpha_i\gt0$ only for points on the margin: the support vectors. $b=y_s-\mathbf w^\top\bx_s$ for any support vector $s$.

Prediction:

$$f(\bx)=\sum_{i\in\text{SV}}\alpha_iy_i\,\hl{\bx_i^\top\bx}+b$$

Keep an eye on the blue dot products: they are the door to kernels.

Support Vector Machine (SVM): Kernels

Some data can't be separated by any hyperplane. Fix: map every point to a richer feature space, $\bx\mapsto\phi(\bx)$, where a hyperplane does separate them.

Simplest example, in 1-D: the blue class sits in the middle, red on both sides. No single threshold works.

Add the feature $x^2$. In the plane $(x,x^2)$ the points lie on a parabola, and a horizontal line separates them.

Back on the original axis, that line is two thresholds: a hyperplane in $\phi$-space is a curved boundary in $\bx$-space.

Support Vector Machine (SVM): Kernels

$$\phi(\bx)=\big(x_1,\ x_2,\ e^{-(x_1^2+x_2^2)}\big)\in\R^3$$
$$\langle\phi(\bx),\phi(\mathbf z)\rangle=x_1z_1+x_2z_2+e^{-(x_1^2+x_2^2)}e^{-(z_1^2+z_2^2)}$$
  • The inner product in $\R^3$ depends only on a function of the values in $\R^2$.
  • Instead of first creating the vectors in $\R^3$, define functions that directly compute the inner products. We never need the vectors in $\R^3$ for anything else!

Support Vector Machine (SVM): Kernel trick

The dual only involves dot products $\bx_i^\top\bx_j$. Replace them by a kernel function:

$$K(\bx_i,\bx_j)=\phi(\bx_i)^\top\phi(\bx_j)$$

We don't compute $\phi(\bx)$ explicitly: we only compute $K$, which gives the dot product in the higher-dimensional space.

Common kernels:

  • Linear: $K(\bx_i,\bx_j)=\bx_i^\top\bx_j$
  • Polynomial: $K(\bx_i,\bx_j)=(\bx_i^\top\bx_j+c)^d$
  • RBF (Gaussian): $K(\bx_i,\bx_j)=\exp\Big(-\dfrac{\norm{\bx_i-\bx_j}^2}{2\sigma^2}\Big)=\exp\big(-\gamma\norm{\bx_i-\bx_j}^2\big)$

Why the polynomial kernel works (2-D, $c=1$, $d=2$):

$$(\bx^\top\mathbf z+1)^2=x_1^2z_1^2+x_2^2z_2^2+2x_1x_2z_1z_2$$ $$\qquad+2x_1z_1+2x_2z_2+1$$
$$=\phi(\bx)^\top\phi(\mathbf z),\quad\phi(\bx)=\big(1,\sqrt2x_1,\sqrt2x_2,x_1^2,x_2^2,\sqrt2x_1x_2\big)$$

One 2-D dot product instead of building 6 coordinates. For $n=100$ features and degree 3, $\phi$ would have 176,851 coordinates.

Support Vector Machine (SVM): Kernel trick

The final dual problem, with kernels:

$$\max_{\boldsymbol\alpha}\sum_i\alpha_i-\frac12\sum_i\sum_j\alpha_i\alpha_jy_iy_j\,\hl{K(\bx_i,\bx_j)}$$

subject to the same constraints $\sum_i\alpha_iy_i=0,\ \alpha_i\ge0$. The decision function for a new point:

$$f(\bx)=\sum_{i\in\text{SV}}\alpha_iy_i\,\hl{K(\bx_i,\bx)}+b$$

RBF: $f(\bx)$ is a sum of Gaussian bumps, one per support vector, up for $+1$, down for $-1$. $\gamma$ sets their width.

1.00

Small γ: wide bumps, smooth boundary (may underfit). Large γ: narrow bumps that memorize the training set. Tune C and γ together by CV.

Support Vector Machine (SVM): Mercer's cond.

A fundamental property of a good kernel: it must satisfy Mercer's theorem, which ensures that the kernel corresponds to a valid dot product in some feature space. The kernel must generate a positive semi-definite Gram matrix, the kernel matrix.

Given data points $\{\bx_1,\dots,\bx_n\}$, the kernel matrix is

$$K_{ij}=K(\bx_i,\bx_j)$$

$K$ must be positive semi-definite: for any vector $\bv$, $\ \bv^\top K\bv\ge0$. This keeps the SVM optimization problem convex and the solution computationally feasible.

Check for a real feature map: $\bv^\top K\bv=\sum_{i,j}v_iv_j\phi(\bx_i)^\top\phi(\bx_j)=\norm{\sum_iv_i\phi(\bx_i)}^2\ge0$.

Key takeaway: any valid kernel must generate a positive semi-definite kernel matrix.

Primal formulation for soft-margin SVM. Real data overlap, so allow each point a slack:

$$\min_{\mathbf w,b,\boldsymbol\xi}\ \frac12\norm{\mathbf w}^2+\hl{C\sum_{i=1}^n\xi_i}$$ $$\text{s.t. }y_i(\mathbf w^\top\bx_i+b)\ge1-\hl{\xi_i},\ \ \xi_i\ge0$$
  • $\xi_i$ are slack variables that allow some points to be on the wrong side of the margin or the decision boundary: $\xi=0$ outside, $0\lt\xi\le1$ inside the margin, $\xi\gt1$ misclassified.
  • $C$ is the regularization parameter: the trade-off between maximizing the margin and minimizing the violations.
    • Large $C$: narrow margin, fits the training data tightly.
    • Small $C$: wide margin, many violations tolerated.
  • The dual is the same with a box: $0\le\alpha_i\le C$.

Support Vector Machine (SVM): Hinge loss

Eliminate the slacks. Each $\xi_i$ wants to be as small as its constraints allow:

$$\xi_i=\max\big(0,\,1-y_if(\bx_i)\big)\qquad\text{the hinge loss}$$

Substitute, divide by $Cn$, set $\lambda=\frac{1}{Cn}$:

$$J=\frac1n\sum_i\max\big(0,1-y_i(\mathbf w^\top\bx_i+b)\big)+\frac\lambda2\norm{\mathbf w}^2$$

Average loss + L2, the same template as regularized logistic regression. Here the L2 term is the margin.

Points with $\mu\ge1$ sit on the flat part: no influence at all. The logistic loss is never exactly 0, so every point pulls. That is where SVM sparsity comes from.

Support Vector Machine (SVM): Review

Pros

  • Can make use of kernels!
  • Very fast classification!
  • Good performance, even with "smaller" datasets (it only relies on the support vectors).

Cons

  • The training can be slow: roughly $O(m^2)$–$O(m^3)$ with kernels.
  • Only for 2 classes (one-vs-all or one-vs-one for more).
  • No probabilities out of the box (Platt scaling).
  • Scale the features: the margin is a Euclidean distance.
