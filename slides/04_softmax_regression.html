Softmax Regression – Motivation

Labels $y^{(i)}\in\{1,\dots,K\}$, e.g. digits, iris species, vehicle types, damage severity.

One-vs-rest (previous chapter) trains $K$ independent binary classifiers:

  • $K$ separate models, $K$ separate losses.
  • The $K$ outputs don't sum to 1: not a probability distribution.

Softmax regression (multinomial logistic regression): one model, one loss, and the output is a distribution over the $K$ classes.

Same recipe as always: linear scores → probabilities → minus the log-likelihood → gradient descent.

Softmax Regression – Representing the classes

The label is one of $K$ names: setosa, versicolor, virginica. How do we write it as numbers?

Option A · an integer $y\in\{1,\dots,K\}$: setosa = 1, versicolor = 2, virginica = 3.

Compact, but it invents an order and distances: it says virginica is "twice" versicolor and "further" from setosa. None of that is true. Fine for storing labels, wrong as a regression target.

Option B · one-hot vector $\by\in\{0,1\}^K$: a 1 in the position of the true class, 0 elsewhere.

$$y=2\ \longrightarrow\ \by=(0,\,1,\,0)\qquad\text{in general }\ y_k=\mathbb 1[y=k]$$

No order, all classes at the same distance. It is a probability distribution that puts all its mass on the true class. Same trick as one-hot input encoding in chapter 02, now used for the output.

The model will output a vector $\bp=(p_1,p_2,p_3)$ of probabilities, e.g. $(0.1,\,0.7,\,0.2)$. Training pushes $\bp$ towards the one-hot target $(0,1,0)$: the two vectors are directly comparable.

For the whole dataset: $\bY\in\{0,1\}^{m\times K}$, one one-hot row per example. Each row sums to 1.

Softmax Regression – The model

Give each class its own parameter vector $\bth_k\in\R^{n+1}$ and a linear score (logit):

$$z_k=\bth_k^\top\bx,\qquad k=1,\dots,K$$

Stack them: $\ \boldsymbol\Theta=[\bth_1,\dots,\bth_K]\in\R^{(n+1)\times K}$, so $\bz=\boldsymbol\Theta^\top\bx$ and, for all the data, $\mathbf Z=\bX\boldsymbol\Theta\in\R^{m\times K}$.

Turn the scores into probabilities with the softmax:

$$P(y=k\mid\bx;\boldsymbol\Theta)=\mathrm{softmax}(\bz)_k=\frac{e^{z_k}}{\sum_{l=1}^Ke^{z_l}}$$

Prediction: $\ \hat y=\arg\max_k\,\mathrm{softmax}(\bz)_k=\arg\max_k\,\bth_k^\top\bx$.

Softmax Regression – Properties

1 · A valid distribution. Each output is $\gt0$ (exponentials) and they sum to 1 (we divide by their sum).

2 · Shift invariance. Adding the same constant $c$ to every score changes nothing:

$$\frac{e^{z_k+c}}{\sum_le^{z_l+c}}=\frac{e^{c}\,e^{z_k}}{e^{c}\sum_le^{z_l}}=\mathrm{softmax}(\bz)_k$$
  • The parameters are not identifiable: adding the same vector to every $\bth_k$ changes nothing (fix: L2, or $\bth_K=\bzero$).
  • Numerical stability: compute with $\bz-\max_lz_l$ so no exponential overflows.

3 · Log-odds between two classes are linear:

$$\log\frac{P(y=k\mid\bx)}{P(y=l\mid\bx)}=z_k-z_l=(\bth_k-\bth_l)^\top\bx$$

The boundary between any two classes is a hyperplane: the decision regions are convex polygons.

Softmax Regression – K = 2 is logistic regression

With two classes, divide numerator and denominator by $e^{z_1}$:

$$P(y=1\mid\bx)=\frac{e^{z_1}}{e^{z_1}+e^{z_2}}=\frac{1}{1+e^{z_2-z_1}}=\frac{1}{1+e^{-(z_1-z_2)}}$$
$$=g\big((\bth_1-\bth_2)^\top\bx\big)$$

This is logistic regression with $\bth=\bth_1-\bth_2$. Only the difference matters: property 2 again.

Everything we learned for logistic regression is the $K=2$ special case of what follows.

Softmax Regression – Cost function

Labels as one-hot vectors (slide 4): $y^{(i)}_k=\mathbb 1[y^{(i)}=k]$, e.g. class 2 of 3 → $(0,1,0)$.

Write $p^{(i)}_k=P(y=k\mid\bx^{(i)};\boldsymbol\Theta)$.

The model says $y^{(i)}$ is categorical. One formula for every class (only the true class's factor is not 1):

$$P(y^{(i)}\mid\bx^{(i)};\boldsymbol\Theta)=\prod_{k=1}^K\big(p^{(i)}_k\big)^{y^{(i)}_k}$$

Take minus the mean log-likelihood: the categorical cross-entropy,

$$J(\boldsymbol\Theta)=-\frac1m\sum_{i=1}^m\sum_{k=1}^Ky^{(i)}_k\log p^{(i)}_k=-\frac1m\sum_{i=1}^m\log p^{(i)}_{y^{(i)}}$$

Minus the log of the probability given to the correct class. For $K=2$ it is exactly the binary cross-entropy.

Useful form for the derivation: $\ -\log p_y=-z_y+\log\sum_le^{z_l}$.

Softmax Regression – Gradient

Step 1 · derivative by the scores. One example with true class $y$: $\ \ell=-z_y+\log\sum_le^{z_l}$.

$$\frac{\partial\ell}{\partial z_k}=-\mathbb 1[y=k]+\frac{e^{z_k}}{\sum_le^{z_l}}=p_k-y_k\qquad\Rightarrow\qquad\nabla_{\bz}\ell=\bp-\by$$

Predicted distribution minus the one-hot target.

Step 2 · chain rule. $z_k=\bth_k^\top\bx$ depends only on $\bth_k$, and $\nabla_{\bth_k}z_k=\bx$:

$$\nabla_{\bth_k}J=\frac1m\sum_{i=1}^m\big(p^{(i)}_k-y^{(i)}_k\big)\,\bx^{(i)}$$
$$\nabla_{\boldsymbol\Theta}J=\frac1m\bX^\top(\mathbf P-\mathbf Y)$$

$\mathbf P,\mathbf Y\in\R^{m\times K}$: predicted probabilities and one-hot labels. Batch GD: $\boldsymbol\Theta:=\boldsymbol\Theta-\alpha\nabla_{\boldsymbol\Theta}J$.

Softmax Regression – Convexity

$\ell=-z_y+\mathrm{LSE}(\bz)$ with $\mathrm{LSE}(\bz)=\log\sum_le^{z_l}$, and $\bz$ is linear in $\boldsymbol\Theta$. A linear term is convex, so it is enough to show that LSE is convex.

Its gradient is $\bp=\mathrm{softmax}(\bz)$. Differentiating $p_k=e^{z_k}/\sum_le^{z_l}$ gives $\ \partial p_k/\partial z_j=p_k(\mathbb 1[k=j]-p_j)$, so the Hessian is $\ \mathrm{diag}(\bp)-\bp\bp^\top$.

For any vector $\bv$:

$$\bv^\top\big(\mathrm{diag}(\bp)-\bp\bp^\top\big)\bv=\sum_kp_kv_k^2-\Big(\sum_kp_kv_k\Big)^2=\mathrm{Var}_{k\sim\bp}[v_k]\ \ge0$$

It is a variance, so it is never negative: LSE is convex, hence $J$ is convex. $\blacksquare$

Not strictly convex, because of shift invariance. L2 regularization makes it strictly convex.

Softmax Regression – Multiclass metrics

One-vs-restSoftmax
training$K$ binary modelsone joint model
probabilitiesdon't sum to 1a proper distribution
use whenany binary classifier (SVMs); multi-labelmutually exclusive classes

The confusion matrix becomes $K\times K$. Precision, recall and F1 are computed per class (that class vs. the rest), then averaged:

  • macro: plain mean over classes. Every class counts the same (good when rare classes matter).
  • weighted: weighted by class frequency.
  • micro: pool all TP/FP/FN first. For single-label problems it equals accuracy.
